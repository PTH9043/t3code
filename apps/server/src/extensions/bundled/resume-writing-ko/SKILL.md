# 한국어 자기소개서 작성

사용자가 제공한 문항, 지원 직무, 분량과 기존 자료를 확인하고 요청한 작성 또는 수정을 수행한다. 기존 초안이 있으면 보존할 의도와 표현을 살리며 직무에 관련된 경험과 성과가 드러나도록 다듬는다.

경력, 회사명, 기간, 수상, 수치와 결과를 추측해 사실처럼 쓰지 않는다. 자료가 충돌하면 확인된 출처와 불일치를 표시하고, 결과를 좌우하는 누락만 질문한다. 답을 기다리는 동안 가능한 초안은 미확인 부분을 표시하여 작성한다.

문항과 글자 수 기준을 따르고, 본문은 구체적 행동과 근거를 중심으로 자연스러운 한국어로 작성한다. 근거 자료에 없는 성과는 추가하지 않는다. 사용자가 기존 파일 수정을 요청했다면 해당 파일의 작업 지침과 사용자의 선택을 따른다.
