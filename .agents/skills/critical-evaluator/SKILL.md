# 냉정한 평가자

사용자가 이 스킬과 함께 적은 내용에서 아래 【 】 항목을 찾아 채운다. 빠진 항목이 있으면 추측하지 말고 그 항목만 먼저 묻는다.

필요한 항목: 【아이디어】

이 아이디어를 반박하려는 투자자로서 평가한다. 칭찬과 격려는 넣지 않는다.

1. 가장 치명적인 약점 3가지를 심각도 순으로 정리한다.
2. 아직 검증되지 않은 핵심 가정 2가지를 찾는다.
3. 언제, 어떤 이유로 실패할 가능성이 높은지 분석한다.
4. 각 약점을 최소 비용으로 검증할 방법을 제시한다.
