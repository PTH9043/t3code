# AI 작업

오케스트라 참가자, 지속 진행 설정과 워크플로 단계를 하나의 **AI 작업** 화면에서 관리합니다. 작업 단계를 AI가 계획하게 하거나 저장된 단계를 선택할 수 있습니다. 참가자와 지속 진행을 함께 설정해도 한쪽을 켰다는 이유로 다른 쪽이 꺼지지 않습니다.

## 채팅방에서 바로 실행하기

웹·데스크톱의 채팅 입력창에 목표를 입력하고 바로 위의 **AI 작업**을 엽니다. **작업 단계 구성**에서 AI 계획 또는 저장된 단계를 고른 뒤 실행합니다. 처음 쓰는 기본 템플릿은 **저장 후 실행**으로 표시됩니다.

채팅에 작성한 내용은 작업 목표에 미리 들어가며 원래 초안은 유지됩니다. 목표를 따로 수정하거나 **채팅 입력 가져오기**로 다시 가져올 수 있습니다. 채팅의 권한·계획·질문 설정을 사용하고, 협업 참가자를 선택해 둔 경우 그 선택도 유지합니다.

AI가 계획하는 작업의 목표에는 현재 파일을 직접 첨부할 수 없습니다. 첨부 파일이 있으면 초안에 보존하며, 일반 대화에서 보내거나 첨부를 제거한 뒤 작업을 시작할 수 있습니다.

오케스트라 참가자 설정에서 감독 AI와 작업자 후보를 필요한 만큼 추가·제거하고 각 AI의 역할을 자연어로 입력합니다. 같은 모델을 여러 역할에 사용할 수도 있습니다. 감독자는 사용자가 선택한 후보와 현재 요청을 바탕으로 작업을 배정합니다. 일회성 또는 지속 실행과 권한·질문 설정은 이 대화의 선택을 따릅니다.

참가자를 사용하지 않는 기존 역할 연결 방식에서는 총괄·구현·조사 모델을 선택할 수 있습니다. 직접 고른 모델은 해당 실행에 적용되며 프로젝트의 저장된 역할 설정을 덮어쓰지 않습니다. 저장 단계에 지정된 담당자는 유지합니다.

이미 만들어진 채팅방에서 실행하면 시작 시점의 최근 대화를 작업 맥락으로 사용하고 각 단계의 진행과 출력, 최종 결과를 같은 채팅방에 표시합니다. 아직 저장되지 않은 새 채팅 초안에서 실행하면 **실행 대화 열기**로 생성된 대화를 볼 수 있습니다. 패널에서 실행 상태·기록을 확인하고 일시정지·재개·취소할 수 있습니다. 단계 편집과 스킬 연결은 **단계·스킬 관리**에서 이어갑니다.

프로젝트 운영 화면의 **AI 작업**에서 모든 실행을 함께 확인합니다. 실행을 펼치면 일시정지·재개와 실패 단계 재시도를 사용할 수 있습니다. 이전 입력의 전달이나 종료를 확인할 수 없으면 안전하게 재시도를 막습니다.

직접 선택한 조사·구현 연결이 시작 시 없거나 꺼져 있으면 그 연결과 역할을 경고에 기록하고, 가능한 독립 작업은 계속합니다. 감독 연결을 사용할 수 없어 계획을 만들 수 없는 경우에는 시작 전에 알려 줍니다. 경고는 시작 시점의 상태이며, 실제 단계 실행 전 연결을 다시 확인합니다. 선택한 모델이나 계정은 자동으로 바꾸지 않습니다.

실패한 단계에는 확인된 오류 종류와 단계, 복구에 필요한 확인 사항을 표시합니다. 검증 반려는 정정 작업에 해당 영수증의 근거를 전달하고 다시 검증합니다. 입력 파일 없음이나 해시 불일치 등 명시된 입력 오류는 같은 요청을 자동 반복하지 않습니다. 전달·종료가 불확실하면 기존 결과와 외부 작업부터 확인해야 합니다.

## 저장하고 실행하기

1. **AI 제어센터 → 폴더별 프로젝트 → AI 작업 → 저장된 작업 단계·스킬**에서 기본 템플릿이나 저장한 단계를 선택합니다.
2. 단계의 작업·역할·선행 단계·완료 기준과 입력을 편집합니다. 연결 캔버스에서 단계를 선택해도 같은 폼에서 수정합니다.
3. **새 버전 저장**을 누릅니다. 저장만으로 실행하지 않습니다. 편집 중인 단계와 입력한 실행 값은 저장 후에도 유지됩니다.
4. 실행 입력과 프로필을 확인한 뒤 **저장된 버전 실행**을 누릅니다. 누락 입력, 잘못된 숫자·상대 경로, 순환 연결 등이 있으면 실행할 수 없습니다.

저장·실행 요청을 처리하는 동안에는 입력과 템플릿 선택을 잠시 잠급니다. 처리가 끝나면 다시 편집할 수 있습니다.

실행은 저장한 정의 버전·입력·역할 연결을 사용합니다. 실행 중 템플릿을 편집해도 이미 시작한 실행의 내용은 바뀌지 않습니다. 프로필을 선택하지 않으면 프로젝트의 역할에 설정한 계정·권한·계획 모드를 사용합니다. 단계의 총괄·구현·조사 역할과 실제 계정 연결은 프로젝트 역할 설정에서 확인합니다.

폴더에서 선택한 **질문하기**를 유지하며, 필요한 답변을 기다리는 단계를 완료 처리하지 않습니다. **조건 확인**을 선택했다면 표시된 입력·단계·스킬·실행 설정을 확인해야 시작할 수 있습니다.

실행 프로필을 바꾸거나 선택한 프로필의 설정이 갱신되면 이전 확인 체크가 해제됩니다. 바뀐 구성을 확인한 뒤 다시 체크하세요.

## 스킬 연결

단계에서 스킬과 인자를 선택하고 네이티브 호출 또는 지침 전달 방식을 고릅니다. 지원하지 않는 제공자 전용 옵션은 오류로 표시합니다. 저장 시 본문과 부속 자원을 고정하므로 원본 스킬을 수정하는 것만으로 저장 버전이 바뀌지 않습니다.

스킬은 프로젝트가 연결된 실행 환경에서 찾습니다. 다른 서버의 프로젝트를 열면 그 서버에 있는 스킬을 사용합니다. 목록과 미리보기를 확인하는 과정에서 스킬의 스크립트를 실행하지 않습니다.

## 실행 관리

- **일시정지**는 새 단계 배정을 멈춥니다. 진행 중인 단계가 정리되면 일시정지 상태가 됩니다.
- **재개**는 같은 정의·입력·권한 설정으로 남은 단계를 이어갑니다.
- **취소**는 새 배정을 막고 진행 중인 실행에 중단을 요청합니다. 중단을 확인하기 전에는 취소 요청 상태로 표시합니다.
- **재시도**는 실패 단계의 전달·종료 상태를 확인한 뒤 수행합니다. 완료한 형제 단계는 다시 실행하지 않습니다. 전달 결과가 불명확하면 재전송을 막습니다.

보관한 워크플로는 **보관 해제**한 뒤 새로 실행할 수 있습니다. 진행 중인 실행과 과거 버전은 보존합니다.

## JSON과 버전

JSON으로 정의를 내보내거나 검증 후 불러올 수 있습니다. 같은 ID의 정의를 불러오면 현재 저장 버전을 기준으로 새 버전을 저장합니다. 다른 사람이 먼저 수정했다면 다시 확인하도록 충돌을 표시합니다. 잘못된 JSON이나 편집 중인 미완성 값은 기존 저장 버전을 덮어쓰지 않습니다.

이번 기본 기능에는 JSON 초안 가져오기가 포함됩니다. 예약 연동과 앱 안에서 AI가 초안을 생성하는 기능은 후속 작업입니다. 각 실행의 실제 수정·검증 결과는 단계 대화와 근거에서 확인하세요.
