# GLM 계정 연결

**설정 → 제공자 → GLM 연결**에서 Z.AI 계정을 추가합니다. GLM Coding Plan과 일반 Z.AI API 중 사용 중인 계정 유형을 선택하고, 해당 API 키와 사용하려는 모델 ID를 입력합니다. 모델 ID를 여러 개 입력할 때는 쉼표로 구분합니다.

연결은 OpenCode를 통해 실행됩니다. 설정을 저장할 때 API 키와 모델의 사용 가능 여부를 자동 검증하지 않으며, 처음 사용할 때 연결 오류가 나타나면 계정 유형·키·모델 ID를 확인하세요. 기존에 선택한 모델이나 다른 제공자 계정은 바뀌지 않습니다.
