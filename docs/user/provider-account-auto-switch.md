# 계정 자동 전환

설정 → AI 제공자 및 CLI 계정에서 **Codex 자동 전환**과 **Claude 자동 전환**을 각각 켜거나 끌 수 있습니다. 기본값은 꺼짐입니다. 선택한 장치의 서버에 저장되므로 웹·데스크톱·모바일에서 같은 서버에 연결하면 같은 정책을 사용합니다. 모바일 앱에서는 서버에 설정된 정책으로 대화를 실행하며, 설정 변경 화면은 웹·데스크톱에 제공됩니다.

Codex는 주간 한도를 모두 사용했더라도 사용 가능한 크레딧이 남아 있으면 현재 계정을 계속 사용합니다. 전환이 필요하면 주간 한도가 남은 계정을 먼저 선택하고, 그다음 크레딧이 남은 계정을 선택합니다. 한도 정보가 없는 계정을 사용량 소진으로 판정하지 않습니다. Codex 계정 카드에서는 주간 한도만 표시하고, 크레딧은 사용 가능할 때만 표시합니다. Claude의 5시간·주간 한도 표시는 유지합니다.

실제 요청에서 HTTP 429 오류가 확인되면 크레딧이 있어도 그 계정을 5분 동안 자동 전환 후보에서 제외합니다. 실행이 끝난 상태에서 다른 계정을 선택하며 같은 대화창에 전환 내역이 남습니다. 실패한 요청을 자동 재전송하지 않습니다. 다음 입력은 새 계정을 사용하고 기존 대화 내용을 인계합니다. 새 계정을 선택할 때 모델과 effort 설정은 유지합니다.

전환 후보는 같은 제공자와 모델을 지원하고 설치·로그인이 확인된 별도 계정입니다. 같은 로그인 경로를 두 이름으로 등록한 경우는 별도 계정으로 취급하지 않습니다. 다른 계정이 없으면 현재 계정의 오류를 그대로 표시합니다. 실행 중인 작업이나 보충 입력에서는 계정을 바꾸지 않습니다.

지속 개발 조직의 Main·Architect·Owner 바인딩과 자동 작업의 고정 프로필은 자동 전환 대상에 포함하지 않습니다. 해당 영역의 계정 변경은 바인딩과 인수인계 절차를 통해 적용해야 합니다. 자동 전환은 다른 제공자로 모델을 바꾸거나 새로운 계정에 자동 로그인하는 기능이 아닙니다.
