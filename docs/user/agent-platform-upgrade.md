# MCP, 확장 도구와 CLI 대화

프로젝트 제어센터에서 AI의 도구, 디자인 참고 자료와 완료 후 검증을 관리할 수 있습니다. 웹과 데스크톱은 같은 기능을 제공하며, 모바일 프로젝트 실행 화면에서도 설정과 기록을 확인할 수 있습니다.

## MCP와 스킬·플러그인

MCP 서버 등록에서 로컬 실행 명령 또는 HTTP 주소를 입력하고 Codex·Claude·Grok 중 사용할 AI를 선택하세요. 인자·환경 변수·HTTP 헤더는 JSON으로 입력합니다. `${ENV_NAME}`과 `${ENV_NAME:-기본값}`은 서버 환경 변수에서 읽습니다. 연결 검사에서 서버 버전, 도구 목록과 실패 이유를 확인할 수 있습니다.

기본 도구의 사용 여부를 프로젝트별로 바꿀 수 있습니다. ‘환경 기본 설정 사용’으로 되돌릴 수 있고, 추가 서버는 환경 전체 또는 해당 프로젝트 폴더와 하위 작업 폴더에 적용됩니다. 변경은 새 AI 세션부터 반영됩니다. Figma처럼 계정이 필요한 서버는 해당 서비스의 인증 정보가 있어야 사용할 수 있습니다.

스킬·플러그인에서 설치된 확장 도구와 출처를 확인하세요. 플러그인은 설치된 CLI가 제공하는 작업만 표시됩니다. Codex의 add/remove, Claude의 설치·업데이트·사용 전환, Grok의 Git 플러그인 관리를 사용합니다. Grok 플러그인 설치에는 출처의 도구·훅 실행 허용을 직접 선택해야 합니다.

로컬 스킬은 서버에 있는 `SKILL.md` 폴더의 절대 경로로 설치합니다. 프로그램에서 설치한 스킬은 업데이트·끄기·켜기·설치 해제를 지원합니다. 업데이트는 최초 출처 폴더를 다시 읽습니다. 기존 외부 스킬은 출처와 목록을 표시하며 그 설치 도구에서 관리합니다. 스킬과 Claude 프로젝트 플러그인은 프로젝트 범위, Codex·Grok 플러그인은 CLI의 사용자 범위를 사용합니다.

## 작업과 검증

작업 대시보드는 세션, 답변·승인 요청, 계획 진행과 백그라운드 활동에서 실제 상태를 표시합니다. ‘완료’는 AI 응답 완료입니다. 테스트 통과 여부는 자동 검증 실행 기록에서 확인하세요.

완료 후 자동 검증은 기본적으로 꺼져 있습니다. Git 작업 공간에서 사용할 포맷 명령과 검증 명령을 줄마다 하나씩 저장하세요. 포맷 후 체크포인트를 저장하고, 검증은 백그라운드에서 실행합니다. 각 명령의 종료 코드, 실행 시각과 마지막 출력이 대화에 남습니다. 포맷은 명령당 20초, 검증은 120초까지 실행하며 각각 최대 6개입니다.

검증 명령이 모두 실제로 성공했을 때만 결과를 작업 기억에 저장하고 선택한 후속 작업을 1회 실행합니다. 실패하거나 새 작업이 시작되면 저장과 후속 실행을 보류합니다. 자동 후속 작업에는 다시 같은 자동화를 실행하지 않습니다. 실행 중 서버가 종료되면 이미 시작된 명령을 자동으로 반복하지 않으므로 기록을 확인하세요.

## 디자인 참고 자료

RAG 자료에 화면 설명, 버전, 컴포넌트, 레이아웃과 원본 링크를 함께 저장할 수 있습니다. 이미지 주소 또는 이미지 파일을 추가하세요. PNG·JPEG·WebP·GIF 파일은 이미지당 8 MB, 자료당 최대 8개를 보관하며 연결된 기기에서 미리 볼 수 있습니다. 이미지 자체를 보관하지만 자동 시각 분석은 수행하지 않습니다. 분석 내용은 화면 설명에 기록하세요. 내용과 디자인 설명·버전·컴포넌트는 RAG 검색에 반영됩니다.

## CLI 대화 이어오기

CLI 대화 이어오기에서 Codex·Claude JSONL, `grok export <세션 ID>`로 만든 Markdown, 또는 T3 JSON을 선택하세요. 메시지 미리보기를 확인한 뒤 이어갈 AI와 모델을 골라 새 대화로 가져옵니다. 가져오기는 AI를 실행하지 않으며 다음 메시지를 보낼 때 이전 대화와 보관 원본 경로를 인계합니다.

원본 텍스트는 그대로 보관하므로 CLI의 도구·할일 기록을 다시 확인할 수 있습니다. 대화 메시지는 최대 1,000개, 합계 200만 자, 원본과 T3 내보내기는 8 MB까지 지원합니다. ‘T3 내보내기’는 메시지, 활동, 계획, 체크포인트와 보관 원본을 포함합니다. ‘보관된 CLI 원본’은 가져온 파일을 그대로 내려받습니다. 외부 이미지 파일, 실행 중 프로세스나 원래 CLI 세션 인증은 이전하지 않습니다.
