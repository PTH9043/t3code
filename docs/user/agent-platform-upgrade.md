# MCP, 확장 도구와 CLI 대화

프로젝트 제어센터에서 AI의 도구, 디자인 참고 자료와 완료 후 검증을 관리할 수 있습니다. 웹과 데스크톱은 같은 기능을 제공하며, 모바일 프로젝트 실행 화면에서도 설정과 기록을 확인할 수 있습니다.

## MCP와 스킬·플러그인

MCP 서버 등록에서 로컬 실행 명령 또는 HTTP 주소를 입력하고 Codex·Claude·Grok 중 사용할 AI를 선택하세요. 인자·환경 변수·HTTP 헤더는 JSON으로 입력합니다. `${ENV_NAME}`과 `${ENV_NAME:-기본값}`은 서버 환경 변수에서 읽습니다. 연결 검사에서 서버 버전, 도구 목록과 실패 이유를 확인할 수 있습니다.

기본 도구의 사용 여부를 프로젝트별로 바꿀 수 있습니다. ‘환경 기본 설정 사용’으로 되돌릴 수 있고, 추가 서버는 환경 전체 또는 해당 프로젝트 폴더와 하위 작업 폴더에 적용됩니다. 변경은 새 AI 세션부터 반영됩니다. Figma처럼 계정이 필요한 서버는 해당 서비스의 인증 정보가 있어야 사용할 수 있습니다.

스킬·플러그인에서 설치된 확장 도구와 출처를 확인하세요. 플러그인은 설치된 CLI가 제공하는 작업만 표시됩니다. Codex의 add/remove, Claude의 설치·업데이트·사용 전환, Grok의 Git 플러그인 관리를 사용합니다. Grok 플러그인 설치에는 출처의 도구·훅 실행 허용을 직접 선택해야 합니다.

스킬·플러그인 화면에서 제공자를 정하거나 계정을 선택한 뒤, 서버의 `SKILL.md` 폴더 경로나 `https://github.com/소유자/저장소/tree/브랜치/스킬경로` 형식의 공개 GitHub 폴더 주소를 입력합니다. OpenAI·Anthropic 스킬 목록을 열어 원하는 폴더 주소를 복사할 수 있고, **한국어 자기소개서 스킬 설치**로 T3 제공 예시를 설치할 수도 있습니다. GitHub 스킬은 설치 시 리비전과 파일을 대조하며 업데이트는 저장된 출처를 다시 읽습니다. API 호출이 제한되면 서버에 설치된 Git으로 가져옵니다. 개인 저장소 로그인과 GitHub 외 사이트는 이 경로에서 지원하지 않습니다. ChatGPT의 개별 GPT는 이 스킬과 별도이므로 직접 가져오지 않습니다. 프로젝트 화면에서는 스킬을 현재 프로젝트 또는 선택한 계정에 설치할 수 있습니다. 계정을 지정하면 해당 계정의 설치 목록과 설정을 사용합니다. 프로그램에서 설치한 스킬은 업데이트·끄기·켜기·설치 해제를 지원합니다. 업데이트는 최초 출처를 다시 읽습니다. 기존 외부 스킬은 출처와 목록을 표시하며 그 설치 도구에서 관리합니다. 스킬과 Claude 프로젝트 플러그인은 프로젝트 범위, Codex·Grok 플러그인은 CLI의 사용자 범위를 사용합니다. 대화 입력창에서 `$`를 입력하면 현재 AI의 스킬과 해당 대화 작업 폴더의 프로젝트 스킬을 표시합니다. Codex와 Claude 대화는 작업 트리의 스킬을 우선하고, 없는 이름은 같은 프로젝트 원본의 스킬에서도 찾습니다. Claude는 선택한 스킬을 현재 세션에 다시 불러오며 선택한 권한과 모델을 유지합니다. 실행 중인 스킬의 내용이 바뀌었다면 현재 작업이 끝난 뒤 다시 선택하세요. 한 요청에서 수동 전용 스킬을 여러 개 선택하면 실행하지 않고 나누어 요청하도록 알립니다. Grok 대화는 해당 작업 트리의 스킬 폴더를 기준으로 합니다.

스킬을 설치하거나 업데이트하면 스킬 파일을 실행하거나 외부 검사 서비스로 보내지 않고 정적 검사합니다. 목록에서 설치 당시 발견된 징후의 종류와 상대 파일 경로·줄을 확인할 수 있습니다. 일부 파일을 크기 제한, 심링크, 인코딩 또는 읽기 오류 때문에 살펴보지 못한 경우에는 검사가 불완전하다고 표시합니다. Windows에서 내부 링크를 복사할 권한이 없으면 검사 단계 이전에 설치가 실패할 수 있습니다. 검사 결과에는 파일 내용이나 인증정보 값을 담지 않습니다. 이름에 민감한 값이 들어간 것으로 보이면 해당 경로 일부를 숨깁니다. 기존 설치 중 검사 기록이 없는 항목은 기록이 없다고 표시되며, 설치 후 별도로 바꾼 파일은 마지막 검사 결과에 반영되지 않습니다.

이 검사는 제한된 패턴을 찾는 참고 정보이며 악성 여부나 안전을 판정하지 않습니다. 정상적인 예시가 징후로 표시되거나 새로운 위험을 놓칠 수 있습니다. 플러그인과 이후 실행 중에 받아오는 파일은 이 검사 범위에 포함되지 않습니다. 검사 결과만으로 설치, 선택한 모델·권한·모드 또는 일반 대화 작업을 차단하지 않습니다.

같은 스킬에 대한 설치·업데이트·사용 전환·삭제는 차례로 처리합니다. 업데이트와 기존 스킬 복원이 모두 실패하면 원본은 별도 백업에 남고 화면에 그 위치가 표시됩니다. 다른 작업의 잠금이 2분 안에 풀리지 않으면 잠금 위치를 표시합니다. 서버가 비정상 종료된 경우에는 스킬 목록을 확인하거나 해당 스킬을 다시 관리할 때, 같은 시스템의 원래 프로세스가 종료됐음을 확인할 수 있으면 잠금을 회수합니다. 연결된 이전 백업이 하나이고 무결성을 검증할 수 있으면 스킬을 복원하며 백업 원본도 보존합니다.

원래 프로세스가 살아 있거나 종료 여부를 확인할 수 없으면 잠금을 보존합니다. 구형 잠금, 출처가 불명확하거나 여러 개인 관련 백업도 추측해서 복구하거나 삭제하지 않으며 확인이 필요한 경우 화면에 알립니다. 대상과 연결할 근거가 없는 구형 백업만으로 무관한 새 스킬 설치를 막지는 않습니다. Windows의 자동 확인에는 사용 가능한 Python과 시스템 프로세스 정보 조회가 필요하며, 조회할 수 없으면 자동 복구하지 않습니다.

## 작업과 검증

작업 대시보드는 세션, 답변·승인 요청, 계획 진행과 백그라운드 활동에서 실제 상태를 표시합니다. ‘완료’는 AI 응답 완료입니다. 테스트 통과 여부는 자동 검증 실행 기록에서 확인하세요.

완료 후 자동 검증은 기본적으로 꺼져 있습니다. Git 작업 공간에서 사용할 포맷 명령과 검증 명령을 줄마다 하나씩 저장하세요. 포맷 후 체크포인트를 저장하고, 검증은 백그라운드에서 실행합니다. 각 명령의 종료 코드, 실행 시각과 마지막 출력이 대화에 남습니다. 포맷은 명령당 20초, 검증은 120초까지 실행하며 각각 최대 6개입니다.

검증 명령이 모두 실제로 성공했을 때만 결과를 작업 기억에 저장하고 선택한 후속 작업을 1회 실행합니다. 실패하거나 새 작업이 시작되면 저장과 후속 실행을 보류합니다. 자동 후속 작업에는 다시 같은 자동화를 실행하지 않습니다. 실행 중 서버가 종료되면 이미 시작된 명령을 자동으로 반복하지 않으므로 기록을 확인하세요.

## 디자인 참고 자료

RAG 자료에 화면 설명, 버전, 컴포넌트, 레이아웃과 원본 링크를 함께 저장할 수 있습니다. 이미지 주소 또는 이미지 파일을 추가하세요. PNG·JPEG·WebP·GIF 파일은 이미지당 8 MB, 자료당 최대 8개를 보관하며 연결된 기기에서 미리 볼 수 있습니다. 이미지 자체를 보관하지만 자동 시각 분석은 수행하지 않습니다. 분석 내용은 화면 설명에 기록하세요. 내용과 디자인 설명·버전·컴포넌트는 RAG 검색에 반영됩니다.

## 대화 캐릭터와 말투

웹과 데스크톱의 대화 캐릭터 메뉴에서 1번 95식, 2번 K2, 3번 OTs-14를 선택할 수 있습니다. 설정은 대화별로 저장되며 작업자의 대화에도 별도로 지정할 수 있습니다. 다음 요청부터 각각 차분하고 정중한 말투, 밝고 친근한 말투, 침착하고 전문적인 말투를 AI에 전달합니다. 사용자의 지시와 원하는 언어·문체가 우선이며, 문체 때문에 작업 수행이나 답변의 충분한 설명을 줄이지 않습니다. 표시 안 함을 선택하면 이 말투 지침도 적용되지 않습니다.

세 캐릭터의 Live2D 모델과 실행 파일이 설치되어 있으면 인터넷 연결 없이 움직이는 캐릭터가 표시됩니다. 실행 파일이나 모델을 불러오지 못하면 설치된 정지 미리보기가 표시됩니다. 이 자료는 개인 사용을 위해 별도로 내려받으며 소스 저장소에는 포함되지 않습니다. 다른 기기나 빌드에 적용하려면 해당 환경에도 파일이 필요합니다.

## CLI 대화 이어오기

CLI 대화 이어오기에서 Codex·Claude JSONL, `grok export <세션 ID>`로 만든 Markdown, 또는 T3 JSON을 선택하세요. 메시지 미리보기를 확인한 뒤 이어갈 AI와 모델을 골라 새 대화로 가져옵니다. 가져오기는 AI를 실행하지 않으며 다음 메시지를 보낼 때 이전 대화와 보관 원본 경로를 인계합니다.

원본 텍스트는 그대로 보관하므로 CLI의 도구·할일 기록을 다시 확인할 수 있습니다. 대화 메시지는 최대 1,000개, 합계 200만 자, 원본과 T3 내보내기는 8 MB까지 지원합니다. ‘T3 내보내기’는 메시지, 활동, 계획, 체크포인트와 보관 원본을 포함합니다. ‘보관된 CLI 원본’은 가져온 파일을 그대로 내려받습니다. 외부 이미지 파일, 실행 중 프로세스나 원래 CLI 세션 인증은 이전하지 않습니다.
