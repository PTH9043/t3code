# 프로그램 허브 메모리

제어센터의 프로그램 등록에서 메모리 상한, 동시 실행 그룹, 공유 데이터셋을 지정할 수 있습니다.

- **메모리 상한**은 Windows 환경에서 각 프로세스에 적용됩니다. 프로그램이 자식 프로세스를 만들면 자식도 같은 상한을 적용받습니다. 프로세스 트리 전체의 합계 상한은 아닙니다. 다른 운영체제에서는 전달받은 한도를 프로그램이 직접 적용해야 합니다.
- **동시 실행 그룹**은 프로젝트별로 구분됩니다. 슬롯을 비우면 1개를 사용합니다. 같은 그룹에 서로 다른 슬롯 수를 지정하면 가장 작은 값이 적용됩니다. 실행 중인 프로그램의 기존 제한도 종료할 때까지 고려합니다.
- 슬롯을 기다리는 프로그램은 **시작 대기**로 표시됩니다. **중지**로 대기를 취소할 수 있습니다. 지원하는 프로그램이 대기를 양보하면 60초 뒤 다시 실행을 시도하며, 중지·비활성화·삭제하면 재실행을 취소합니다. 서버가 재시작되면 남은 대기는 취소됩니다.
- **공유 데이터셋**은 `이름=프로젝트 내 상대 경로`를 한 줄씩 입력합니다. 이름은 중복할 수 없습니다. 경로는 해당 프로그램에 `T3_HUB_DATASET_이름` 환경변수로 전달됩니다.

메모리 공유에는 프로그램의 지원이 필요합니다. 허브에 경로를 등록하는 것만으로 JSON 파일이 자동 변환되거나 프로그램의 객체가 공유되지는 않습니다. Arrow 바이너리 파일을 준비하고 메모리 매핑으로 읽는 프로그램은 파일 데이터를 공유할 수 있습니다. 전체 데이터를 다시 Python 객체로 변환하면 메모리 사용량이 늘어납니다. JSON 매니페스트는 파일 위치와 검증 정보를 기록하는 작은 메타데이터입니다.

Windows의 메모리 제한은 사전 빌드된 C++ 가드가 적용합니다. 메모리 상한은 프로그램의 라이브러리 초기화에 필요한 양도 포함해야 합니다. 너무 낮게 지정하면 시작 단계에서 메모리 부족으로 종료될 수 있습니다.
