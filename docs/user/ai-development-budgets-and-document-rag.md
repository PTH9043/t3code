# 문서 검색과 AI 개발 예산

대화 입력창에 여러 파일을 드래그하거나 `+`로 선택한 뒤 메시지를 보내면 지원되는 문서를 검색 자료로 등록합니다. 같은 프로젝트의 다음 대화에서도 질문과 관련된 부분을 찾아 AI에게 전달합니다. 원본은 첨부 카드에서 계속 열거나 다운로드할 수 있습니다.

텍스트 PDF, Word `.docx`, Excel `.xlsx`, 텍스트·Markdown·CSV·TSV와 일반 코드 파일을 지원합니다. 답변 근거에는 파일명과 PDF 페이지, Word 문단, Excel 시트·행·셀, 텍스트 줄 위치가 포함됩니다. 글자가 없는 스캔 PDF는 한국어·영어 로컬 OCR로 인식합니다. 이전 `.doc`·`.xls` 형식과 Excel 수식의 재계산은 지원하지 않습니다. Excel은 저장된 수식 결과와 값을 읽습니다. 서식과 날짜 표시를 정확하게 확인해야 하면 원본을 확인하세요.

대화에 첨부한 PDF는 페이지별로 나누어 색인하고, 긴 문서도 순서대로 처리하며 중단 후 이어갑니다. AI에는 모델의 입력 여유와 질문에 맞는 부분을 나누어 전달하므로 전체 원문을 한 번에 보내지 않습니다. 처리하지 못한 페이지나 검색 범위가 있으면 부분 처리로 표시합니다. 첨부 파일 한도는 10MB입니다. 지원하지 않는 파일과 추출 실패도 원본 첨부는 유지됩니다. 질문과 맞는 검색 결과가 없으면 AI가 원본이나 추출 파일의 필요한 범위를 확인하도록 안내합니다.

스캔과 이미지가 포함된 페이지는 텍스트와 빈 페이지를 구별해 확인이 필요한 부분을 표시합니다. 설정 → 일반 → AI 검색·문서 인식에서 OCR을 켜면 한국어·영어를 로컬에서 인식합니다. 신뢰도가 낮거나 일부 페이지를 읽지 못하면 확인 안내를 표시합니다. 이미지 입력을 지원하는 AI는 필요한 페이지를 이미지로 받아 표나 그림을 확인할 수 있습니다. 이미지 전달 기록은 실제 의미 해석이 정확하다는 보증은 아닙니다. 이미지를 지원하지 않거나 확인하지 못한 모델은 해당 페이지를 미확인으로 남깁니다. 복잡한 표 구조, 숫자·날짜·금액은 원본 페이지와 대조하세요. OCR을 처음 사용할 때 언어 모델을 내려받으며 문서 이미지는 서버에서 로컬로 처리합니다.

추출 결과는 파일 내용의 해시와 파서 버전으로 재사용합니다. 같은 첨부의 내용이 바뀌면 해당 검색 자료를 갱신하며, 서로 다른 첨부는 파일명이 같아도 별도로 유지합니다. 자료는 프로젝트 안에서만 자동 검색합니다. 자료를 보관 처리하거나 대화·프로젝트를 삭제하면 검색 대상에서 제외됩니다. 대화 되돌리기로 제거한 첨부도 검색에서 제외됩니다. 검색 자료를 제외하는 것과 디스크의 추출 캐시를 지우는 것은 별개의 동작입니다.

Main 개발 패널의 자동 목표에는 목표 토큰 예산을, 구성에는 프로젝트 일일 토큰 예산을 설정할 수 있습니다. 빈 값은 상한 미설정입니다. 보고된 사용량의 80%에서 경고하고, 상한에 도달하면 새로운 자동 Main·Owner 실행과 배정을 보류합니다. 실행 중인 작업을 강제로 중단하지 않으므로 실제 총량은 한도를 넘을 수 있습니다. 보고가 늦거나 제공자가 토큰을 보고하지 않는 경우에도 정확한 비용 상한을 보장하지 않습니다.

목표 사용량에는 Main·Owner·재시도가 포함됩니다. 직접 입력으로 이어간 활성 목표의 Main 작업도 집계합니다. 일일 사용량은 서버의 현지 날짜를 기준으로 프로젝트 전체 요청을 합산하며, 자정을 걸친 요청은 시작한 날짜에 포함됩니다. 캐시 읽기는 입력 토큰에 포함된 값이므로 총량에 다시 더하지 않습니다. 미집계는 0이 아니라 미집계로 표시합니다. 금액 환산이나 절감률을 추정하지 않습니다.

같은 요청의 중간 사용량 보고에서 입력·출력·캐시 등의 항목이 빠져도 이전에 확인한 기준값은 유지합니다. 해당 항목이 다시 보고되면 그 기준 이후의 증가분을 반영하며, 같은 누적값을 다시 받아도 사용량에 중복해서 더하지 않습니다. 요청이 바뀔 때는 마지막 실제 보고로 확인할 수 있는 증가분만 새 요청에 반영하며, 이전 요청에서 확인하지 못한 사용량을 새 요청에 넘겨 집계하지 않습니다.

오케스트라 작업 목록에서는 선행 작업·사용자 답변·검증 결과를 기다리는 이유와 완료된 시도의 실행 시간을 확인할 수 있습니다. 단계를 펼친 뒤 **이 단계의 토큰 사용량 보기**를 누르면 해당 단계의 모든 시도를 합산한 보고를 조회합니다. 실행 시간에는 대기 시간과 아직 실행 중인 시도는 포함되지 않습니다. 단계별 사용량은 전체 작업 합계에 이미 포함되므로 다시 더하지 않습니다.

회의 발언·의장 정리·계획 생성의 실패 횟수는 실행 기록에 보존됩니다. 서버를 재시작해도 소진된 재시도 한도가 새로 생기지 않으며, 완료된 발언과 단계는 유지됩니다.

사용자는 멈춘 목표의 한도·횟수·시간을 수정한 뒤 재개할 수 있습니다. 같은 목표를 재개하면 기존 사용량과 실행 기록을 보존합니다. 직접 보낸 Owner 작업은 자동 예산 제어 중에도 실행할 수 있습니다.

같은 코드와 요구사항에서 같은 실행 실패가 세 번 반복되거나, 수정되지 않은 후보에서 같은 검증이 두 번 실패하면 자동 진행을 멈춥니다. 원인을 해결한 뒤 재개하면 새 시도의 실패를 다시 세며, 이전 실패 기록과 누적 토큰 사용량은 보존합니다. 재시작 후 Main의 입력·완료 응답·진행 기록·원래 AI 세션을 확인할 수 있으면 완료된 단계에서 이어갑니다. 입력 전달 여부가 불명확하면 자동 재전송하지 않고 확인이 필요한 상태로 남깁니다.

Owner 실패에는 네트워크·실행 환경·검증·요구사항·전달 불확실성에 따른 복구 안내를 남깁니다. Main은 복구 전략을 지정하고 다시 배정합니다. 전송 전의 일시적 네트워크 오류는 같은 코드에서 한 번 재시도할 수 있습니다. 검증 실패가 그대로 남았으면 코드 수정이나 다른 전략이 필요합니다. 세션·작업 기록에서 이 안내를 확인할 수 있습니다.
