# 파일 첨부

AI가 답변을 요청하는 Question에도 사진을 첨부할 수 있습니다. 웹과 데스크톱에서는 질문이 열린 상태에서 `+`, 드래그 앤 드롭 또는 붙여넣기를 사용하세요. 모바일에서는 질문의 `사진 첨부`를 누릅니다. 질문마다 미리보기와 제거 버튼이 있으며, 사진만으로 답하거나 선택지·직접 답변과 함께 보낼 수 있습니다.

Codex의 비동기 Question에는 사진을 이미지 입력으로 전달합니다. 답변을 텍스트만 받을 수 있는 Question에서는 사진을 서버에 저장하고 파일 경로를 답변에 전달합니다. 이 경우 모델이 사진을 읽을 수 있는지는 해당 실행 환경의 파일 접근 권한과 도구에 따라 달라집니다.

AI 작업의 오케스트라 질문에서는 웹·데스크톱의 아래 입력창에 사진을 첨부하고 답변을 보내거나 선택지를 누르세요. 사진은 서버에 저장되며, 실행 중인 모델에 파일 경로와 함께 전달됩니다.

대화 작성창의 `+` 버튼을 누르면 여러 파일을 한 번에 선택할 수 있습니다. 파일 탐색기에서 파일을 대화 화면이나 작성창으로 끌어다 놓아도 첨부됩니다.

왼쪽 프로젝트 이름에 파일을 놓으면 해당 프로젝트의 대화 초안에 첨부됩니다. 열어 둔 같은 프로젝트의 대화를 우선 사용하고, 대화가 없으면 새 초안을 엽니다. 같은 저장소 안에 있는 다른 폴더의 초안과 첨부 파일도 각각 보존합니다. 파일을 놓는 동작만으로 메시지가 전송되지는 않습니다.

Windows에서는 관리자 권한으로 실행한 앱에서도 탐색기의 파일을 받을 수 있습니다. 앱 내부에서 탭을 옮기거나 파일을 작성창으로 끌어놓는 동작도 함께 지원합니다. 탐색기에서 끌어놓는 이미지는 원본 파일당 50MB까지 받고 전송 제한에 맞춰 압축합니다. 읽지 못한 파일과 용량 제한을 넘긴 파일은 오류로 안내합니다.

사진을 놓으면 작성창에 이미지 미리보기가 나타납니다. 왼쪽 프로젝트에 놓았을 때는 해당 대화의 작성창에서 확인할 수 있습니다. 보내기 전에 첨부한 파일 이름과 크기를 확인하고, 각 파일의 `×` 버튼으로 첨부를 제거할 수 있습니다. 메시지를 보내면 파일과 질문이 함께 AI에 전달됩니다. 질문 없이 파일만 보내는 것도 가능합니다.

Windows 드래그에서는 JPEG·PNG·GIF·WebP의 파일 내용을 확인해 이미지를 판별합니다. JFIF 사진이나 확장자가 없는 이미지도 일반 파일 카드 대신 이미지 미리보기로 표시합니다. 대화의 툴팁이 놓는 위치를 가려도 아래의 첨부 영역을 찾으며, 모달 대화상자가 입력을 막고 있을 때는 첨부하지 않습니다. 처리할 대상이나 이미지 미리보기를 찾지 못하면 안내를 표시합니다.

웹·데스크톱에서는 문서를 파일당 50MB까지 첨부할 수 있습니다. 메시지 하나에 이미지와 문서를 합쳐 최대 8개, 합계 50MB까지 받습니다. 합계를 넘으면 파일을 나누어 보내세요. 이미지는 원본 파일당 50MB까지 받고, AI 이미지 입력으로 보낼 때 10MB 이내로 압축합니다. 모바일의 이미지 입력은 파일당 10MB, 합계 50MB까지입니다.

큰 파일도 작성창에 파일 이름과 크기가 표시되며 원본을 전송합니다. 아직 보내지 않은 큰 파일은 브라우저 임시 저장 용량 때문에 새로고침 후 복원되지 않을 수 있으며, 작성창에 저장되지 않았다는 안내가 나타납니다. 전송한 원본은 서버의 대화 기록에 보관됩니다.

텍스트, 코드, PDF, Office 문서, 스프레드시트 등의 원본 파일을 연결된 실행 환경에 업로드합니다. 이미지는 AI의 이미지 입력으로 전달하고, 문서는 AI가 파일 도구로 읽습니다. 문서 내용을 해석할 수 있는 범위는 선택한 AI와 해당 환경의 파일 읽기 도구에 따라 달라집니다. 읽을 수 없는 형식은 AI에 변환 방법을 요청할 수 있습니다.

전송한 파일은 대화 기록에서 확인하고 내려받을 수 있습니다. 원격 연결에서도 파일이 실행 환경에 업로드되므로 내 PC에만 있는 경로를 AI가 추측할 필요가 없습니다.

웹·데스크톱에서는 AI가 만든 자료의 파일 링크도 내려받을 수 있습니다. ZIP, PDF, Office 문서, 텍스트, CSV, 이미지·동영상 등의 자료 링크를 누르면 파일을 다운로드합니다. 파일 링크 옆의 다운로드 버튼으로도 원본을 받을 수 있습니다. 줄 번호가 붙은 코드 참조와 인라인 경로는 기존처럼 미리보기를 열며, 다운로드 버튼은 별도로 사용할 수 있습니다. 파일이 없거나 해당 대화의 프로젝트 밖에 있으면 오류를 표시합니다.

오케스트라 주제와 Owner 직접 지시에는 현재 텍스트만 보낼 수 있습니다. 첨부 파일을 보내려면 일반 대화나 Main 대화를 사용하세요.
