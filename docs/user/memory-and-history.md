# 장기기억과 전체 이력

대화 원문은 로컬 데이터베이스에 남습니다. 자동 대화 기억이 켜져 있으면 매 요청에 현재 요청과 바로 전 사용자 발언에 관련된 기억, 같은 대화의 최근 발언을 추가합니다. 최근 발언은 최대 30개, 발언마다 최대 2,000자, 합계 약 16,000자로 제한하고 바로 전 사용자 발언을 우선합니다. 현재 메시지 이후의 발언은 이전 대화로 넣지 않습니다. 작업 중 새 단서가 드러나면 에이전트가 그 키워드로 다시 검색하고 필요한 원문을 확인할 수 있습니다. 사용자가 지정한 필수 지침은 검색어와 관계없이 유지합니다. 자동 대화 기억 설정을 끄면 검색된 기억과 최근 대화는 자동으로 추가하지 않습니다.

기억을 준비하는 데 오류가 나면 AI에 누락 사실을 전달하고 활동 기록에 남깁니다. AI가 이전 기억을 확인했다고 가정하지 않도록 상태와 원문을 다시 확인해야 합니다.

장기기억은 프로젝트와 현재 작업 폴더별로 구분합니다. 새 사용자 발언에는 확인된 작업 폴더를 기록하고, 자동 대화 기억과 원문 검색에서 같은 폴더의 기록을 사용합니다. 프로젝트 범위 지식은 프로젝트 루트에 적용하고, 폴더 범위 자료는 지정한 경로에 적용합니다. 사용자가 공용으로 지정한 기억과 필수 공용 지침은 별도로 유지합니다. 진행 중인 할 일과 작업 상태는 장기기억으로 확정하지 않습니다.

기존 대화와 수동 기억 중 저장 당시 폴더가 기록되지 않은 항목은 어느 폴더의 것인지 임의로 정하지 않습니다. 원문은 그대로 보존하지만 폴더별 자동 주입·검색·원문 조회에서 제외하며 누락 사실을 알립니다. 이 기록을 자동으로 모두 읽었다고 볼 수 없습니다. 이전 협업 결과와 지속 작업 상태 역시 폴더 범위를 확인하지 못하면 자동으로 넣지 않고 안내합니다.

일반 채팅에서 실제 존재하는 하위 폴더 경로를 하나 지정하면 그 폴더를 같은 대화의 후속 요청에서도 기억 검색 범위로 유지합니다. 다른 하위 폴더 하나를 지정하면 바뀝니다. 경로가 여러 개여서 구분할 수 없으면 이전 사용자 발언의 폴더가 확인된 경우 그 범위를 유지하고, 이전 범위도 확인되지 않으면 기억 누락을 알립니다. 대화를 되돌리면 남아 있는 대화에서 경로를 다시 찾습니다. 경로 표기가 인식되지 않거나 작업 폴더 확인이 실패하면 폴더별 기억을 임의로 선택하지 않고 AI에 누락 사실을 전달합니다. 자료의 범위를 바꾼 직후에는 기억 색인이 갱신되는 동안 이전 범위의 자료를 전달하지 않습니다.

새 기록에는 원문 ID, 대화·턴 ID, 시각과 검증 상태가 붙습니다. 긴 대화는 원문을 보존하고 나누어 검색하며, 검색된 단어가 있는 부분을 발췌합니다. 사용자 발언과 에이전트의 작업 보고를 구분하며, 에이전트 보고에는 미검증 표시를 유지합니다. 주제별 정리는 원문 발췌와 출처를 모으는 방식입니다. 별도의 유료 모델을 호출해 사실 여부를 판정하지 않습니다. 현재 사용자 지시와 이후의 명시적 정정이 이전 기억보다 우선합니다.

에이전트는 `workspace_memory` 도구로 필요한 자료를 더 읽을 수 있습니다.

| 동작       | 용도                                                                            |
| ---------- | ------------------------------------------------------------------------------- |
| `status`   | 기억 준비 상태와 이력 색인 진행 위치 확인                                       |
| `search`   | 현재 폴더의 기억과 명시적으로 공유한 공용 기억 검색                             |
| `read`     | 현재 폴더 범위의 원문 조회. 긴 원문은 응답의 `next` 위치부터 계속 조회          |
| `history`  | 현재 폴더로 확인된 대화를 20개씩 조회. `next`가 있으면 계속 조회                |
| `export`   | 전체 대화에 다른 폴더나 미분류 기록이 섞일 수 있어 폴더 범위 AI 호출에서는 제한 |
| `remember` | 현재 폴더의 관례·결정·정정을 저장. 공용 저장은 사용자가 명시한 경우에만 사용    |
| `dream`    | 새 관찰을 주제별로 정리하고 기억 목차 갱신                                      |
| `forget`   | 활성 기억 검색과 주제 파일에서 제외. 원래 대화와 이전 버전 보관본은 유지        |

전체 이력이 필요한 감사·분쟁 확인·과거 결정 재검토에서는 폴더별 `history`나 일부 검색 결과만으로 전체 기록을 확인했다고 결론 내리지 않아야 합니다. 폴더를 확인하지 못한 예전 원문과 다른 폴더의 기록은 이 조회에 포함되지 않습니다.

모델을 바꿔도 기억은 같은 로컬 환경에 남습니다. 확인된 현재 폴더의 최근 대화 발췌와 추가 조회 방법을 새 모델에 전달합니다. 다른 폴더나 폴더 미확인 기록이 섞여 있으면 전체 압축 스냅샷은 자동으로 인계하지 않고 누락 사실을 표시합니다.

의미 검색을 켰다면 현재 범위에 속한 전체 청크를 작은 묶음으로 확인합니다. 최신 1,000개로 검색 범위를 제한하지 않습니다. 처음에는 일부 임베딩만 준비될 수 있으며 다음 검색에서 이어서 준비합니다. 임베딩 서비스를 사용할 수 없으면 키워드 검색 결과와 준비 상태를 표시합니다.

완료된 AI 실행 원문은 로컬 파일에서도 보관하고, 원문 조회가 필요할 때 읽습니다. 대화가 길어져도 완료된 원문 전체를 실행기의 메모리에 계속 복제하지 않습니다. 되돌린 턴의 보관 원문도 유지합니다.

오류 상태로 멈춘 AI 세션은 실제 작업, 백그라운드 작업, 승인 또는 사용자 답변 대기가 없으면 1분의 유예 후 정리합니다. 정리 확인은 1분 간격이며 대화 원문과 재개 정보는 보존합니다. 정상 대기 세션의 유휴 기준은 기존과 같은 30분입니다.
