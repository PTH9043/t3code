# Antigravity CLI

T3는 Google 코딩 에이전트를 Antigravity CLI로 실행합니다. 데스크톱과 웹에서는 **설정 → 제공자**에서 사용할 실행 환경을 고르세요.

1.  **CLI 계정 추가 → Antigravity CLI**에서 계정 이름을 입력하고 저장하세요.
2.  추가한 계정 카드의 **Google로 로그인**을 누르세요. 같은 컴퓨터의 브라우저에서 인증이 자동 완료되거나, 원격 환경에서는 화면에 표시된 일회용 코드를 입력해 완료할 수 있습니다.
3.  대화의 모델 선택기에서 연결한 계정과 모델을 고르세요. 사용할 수 있는 모델과 5시간·7일 쿼터 한도는 그 계정의 Antigravity CLI가 제공합니다.

CLI는 T3 서버가 실행되는 컴퓨터에 설치해야 합니다. 실행 파일 이름은 `agy`입니다. 자동으로 찾지 못하면 계정 설정에 실행 파일의 절대 경로를 입력하세요. 모바일에서 접속할 때도 같은 서버의 계정을 사용합니다.

## 스킬·플러그인 및 MCP 도구

- 프로젝트의 `.agents/skills`·`.gemini/skills`, 사용자 `~/.gemini/skills`·`~/.gemini/config/skills`, 활성화된 Antigravity 플러그인(`~/.gemini/config/plugins/*/skills`) 및 내장 스킬을 입력창의 `/` 또는 `$` 자동완성으로 바로 호출할 수 있습니다.
- **설정 → 스킬·플러그인** 및 **MCP 도구**에서 Antigravity 플러그인(`agy plugin`)과 사용자 지정 MCP 서버를 함께 관리할 수 있습니다.
- T3 내장 도구(`t3-code`: 협업 브라우저·장기기억·하위 위임·앱 실행)는 항상 1순위로 연결되며, Antigravity 내장 기능과 중복되는 외부 MCP는 기본 환경 설정에서 자동 제외해 도구 상한 초과를 방지합니다. 세션 중 `t3-code` 도구 누락이 감지되면 새 대화로 옮길 필요 없이 현재 대화에서 `t3-code` 우선 모드로 자동 재연결해 작업을 이어 갑니다.

## 질문 카드

Antigravity가 작업 중 사용자의 결정이 필요하면 답변이 끝난 뒤 입력창 위에 질문 카드가 열립니다. 업그레이드 방에서도 같습니다. 선택지를 고르거나 직접 답을 적어 제출하면 그 답이 다음 메시지로 전달되고 작업이 이어집니다. 모델이 카드 형식을 따르지 않고 질문을 글로만 쓴 경우에도, 답변 맨 끝이 질문 한 줄과 `[1]`, `[2]`… 로 번호를 붙인 선택지로 끝나면 카드로 엽니다. 그 밖의 형태는 글로 남으니 입력창에 직접 답하세요.
