# 대화별 인계 문맥 절약

입력창의 **작업 토큰 사용량**을 열고 **이 대화의 인계 문맥 절약**을 켜세요.
작업이 실행 중이면 끝난 뒤 바꿀 수 있습니다. 기본값은 꺼짐이며, 같은 환경의
웹·데스크톱·모바일에서 같은 대화 설정을 공유합니다.

모델 전환 때문에 새 세션으로 대화 기록을 넘길 때 적용합니다. 같은 세션에서
이어지는 일반 요청이나 자동화가 직접 준비한 요청에는 적용하지 않습니다.
사용하는 모델과 추론 설정은 유지하며, 별도 요약 모델을 호출하지 않습니다.

사용자 발언과 질문 답변, 최근 작업 결과를 원문으로 남기고 과거의 상세한
진행 보고 일부는 필요할 때 조회하도록 보관합니다. 원문은 에이전트가 실행되는
환경에 보관되므로 휴대폰에서 서버의 로컬 파일을 직접 열 필요는 없습니다.
원문 조회에는 해당 에이전트의 파일 읽기 권한이 적용됩니다.

보존할 내용이 많아 충분히 줄어들지 않거나, 이전 첨부 자료·되돌림 이력이 있거나,
원문을 저장·확인하지 못하면 기존 인계를 유지합니다. 최근 준비 내역에 이유가 표시됩니다.

**해제하면 다음 인계부터 기존 방식으로 돌아갑니다.** 이미 실행 중인 세션의
대화 내용을 바꾸거나 과거 메시지를 삭제하지 않습니다.

## 숫자 읽기

`인계 입력 15,000 → 6,000자 · 9,000자 감소`는 준비된 입력의 글자 수 비교입니다.
표시된 내역은 마지막으로 불러온 기록에 있는 인계 준비 시점의 값이며, 제공자에게
전송·처리가 완료됐다는 뜻은 아닙니다. 설정을 꺼도 이전 비교 기록은 남습니다.

입력이 짧아져도 원문 재조회나 추가 응답이 늘면 실제 토큰 절감은 작아질 수 있습니다.
같은 모델·완료 기준으로 [작업 토큰 사용량](./token-usage.md)과 작업 결과를 함께
비교하세요. 제공자의 사용량 보고가 일부라면 전체 절감률로 단정할 수 없습니다.
