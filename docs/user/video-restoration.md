# 영상 복원

데스크톱 앱의 **AI 작업실 → 영상 복원**에서 이 컴퓨터에 설치한 Jasna로 영상을 복원할 수 있습니다. Jasna 실행 파일, 입력 영상, 저장할 파일을 선택하고 **복원 시작**을 누릅니다. T3 데이터 폴더에 설치한 Jasna 0.11.3은 저장된 선택이 없을 때 자동으로 찾습니다. 직접 선택한 실행 파일과 **선택 해제**는 저장되어 다음 실행에도 유지됩니다.

모델을 지정하지 않으면 설치된 Jasna의 기본 설정을 따릅니다. 다른 모델을 직접 선택할 수 있으며, LTX는 Jasna의 후원 라이선스와 해당 모델 파일이 필요합니다. Jasna 설치 경로는 영문만 포함해야 합니다. [Jasna 실행 파일과 모델](https://github.com/Kruk2/jasna/releases)은 별도로 설치되어 있어야 합니다. 첫 실행은 GPU에 맞게 모델을 준비하느라 오래 걸릴 수 있습니다.

원본은 수정하지 않습니다. 이미 존재하는 출력 파일은 덮어쓰지 않으며, 다른 프로그램이 작업 중에 같은 이름으로 파일을 만들면 결과를 임시 파일로 보존하고 위치를 표시합니다. 작업을 중지하거나 실패한 경우에도 임시 파일이 남을 수 있습니다.

작업 상태와 최근 실행 기록은 화면에서 볼 수 있습니다. 다른 화면으로 이동해도 실행 중인 작업은 계속됩니다. 데스크톱 앱을 종료하면 작업이 중단될 수 있으며, 현재 웹 브라우저와 모바일 앱에서는 이 컴퓨터의 Jasna를 직접 실행할 수 없습니다.
