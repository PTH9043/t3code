# 생성 결과 보기

AI가 만든 이미지와 텍스트 파일은 해당 응답 안에 표시됩니다. 이미지와 텍스트를 확인하기 위해 먼저 파일을 다운로드할 필요가 없습니다.

이미지는 원래 비율로 표시됩니다. 이미지를 누르면 앱 안에서 크게 볼 수 있으며, **원본 다운로드**로 실제 파일을 받을 수 있습니다. 여러 결과는 같은 응답에 각각 표시됩니다.

텍스트는 내용이 펼쳐진 상태로 표시됩니다. Markdown 문서는 **원문**과 **읽기**를 전환할 수 있습니다. **전체 복사**는 미리보기에서 잘린 부분을 포함한 원문 전체를 복사합니다. 큰 파일은 일부 내용을 먼저 표시하고 **전체 내용 보기**로 나머지를 읽습니다.

결과 이름을 누르면 텍스트를 접거나 펼칠 수 있습니다. 원본 파일 다운로드도 함께 제공됩니다. 결과를 확인하는 동안 새 창을 자동으로 열거나 입력 위치를 옮기지 않습니다.

대화에 보존된 결과는 다시 접속한 뒤에도 확인할 수 있습니다. 보존이 끝난 결과는 작업 폴더의 원본 파일을 나중에 수정해도 해당 응답에서 바뀌지 않습니다.

현재 이미지와 UTF-8 텍스트 결과는 파일당 최대 64MB까지 보존합니다. 지원하지 않는 자료는 기존 파일 링크로 내려받을 수 있습니다. 결과를 생성하는 기능은 선택한 AI와 연결된 도구의 지원 범위를 따릅니다.
