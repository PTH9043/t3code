# DeepSeek 계정 연결

**설정 → CLI 계정 → DeepSeek 연결**에서 API 플랫폼 계정을 연결합니다. 일반 계정 추가 화면에서도 **DeepSeek API 계정 연결**을 선택할 수 있습니다.

1. **DeepSeek 로그인 / API 키 발급**을 눌러 공식 API 플랫폼에 로그인하고 키를 발급합니다.
2. 연결할 계정 이름과 API 키를 입력합니다.
3. **확인하고 연결**을 누릅니다. 서버가 공식 모델 목록 API로 키를 확인한 뒤 계정을 저장합니다.

연결 후에는 기존 대화창의 모델 목록에서 해당 계정의 DeepSeek 모델을 선택합니다. 지속 작업실과 목표 자동 개발에서도 같은 계정을 사용할 수 있습니다. API 키는 서버에 민감 정보로 보관하며 클라이언트 설정으로 다시 보내지 않습니다. 모델 답변을 생성하지 않고 연결을 확인하므로 연결 확인 자체는 대화를 실행하지 않습니다.

DeepSeek 연결은 API 키 인증을 사용합니다. 웹 채팅 계정의 브라우저 로그인만으로 API가 연결되지는 않습니다. API 플랫폼의 키·사용 권한·잔액은 DeepSeek에서 관리합니다. [공식 인증 문서](https://api-docs.deepseek.com/api/deepseek-api/)

설정의 계정 삭제로 연결을 해제하고 새 연결 창에서 다시 연결할 수 있습니다. 여러 계정도 이름을 달리해 연결합니다. 웹과 데스크톱에서 연결을 설정하고 모바일에서는 서버에 연결된 모델을 선택할 수 있습니다. 실행 환경에 OpenCode가 설치되어 있어야 코딩 작업을 실행할 수 있습니다.
