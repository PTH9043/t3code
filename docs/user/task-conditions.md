# 작업 조건 확인

입력창의 **질문하기**와 **조건 확인** 토글로 요청 방식을 선택합니다. 켜진 토글을 다시 누르면 꺼집니다. 둘 다 꺼져 있으면 요청을 바로 보냅니다. 새 폴더에서는 둘 다 꺼져 있으며, 선택은 폴더별로 기억합니다. 기존에 저장한 선택도 유지합니다.

- **질문하기**: AI가 작업 계획과 필요한 조건을 먼저 묻고 답변을 기다립니다. 단순 질문이나 상태 확인에는 먼저 본문으로 답합니다. 지원하는 실행기에서는 선택 가능한 질문 카드가 표시됩니다.
- **조건 확인**: 새 요청을 AI에 보내기 전에 편집 가능한 양식이 열립니다.

질문하기는 AI가 필요한 조건을 물어보는 방식이고, 조건 확인은 사용자가 양식에서 조건을 직접 정하는 방식입니다. 한 번에 하나만 켤 수 있으며, 다른 토글을 켜면 기존 토글은 꺼집니다.

목표, 대상과 범위, 판단 기준, 수행 순서, 제외 대상, 완료 기준, 결과 형식을 수정하세요. 처음 표시되는 내용은 요청 원문과 현재 폴더를 넣은 기본 초안입니다. AI가 요청을 분석해 만든 계획은 아니므로 필요한 조건을 직접 보완하세요.

허용 행동은 직접 선택해야 합니다. **조회·분석·답변만**을 선택한 일반 대화는 해당 요청을 승인 필요·계획 모드로 전달합니다. 실제 도구의 제한 범위는 연결한 제공자가 지원하는 권한과 계획 모드를 따릅니다. **파일 수정·명령 실행 허용**을 선택해도 설치, 삭제, 외부 서비스 게시·전송은 별도 선택 항목입니다. 세부 범위와 금지 사항은 AI에 지침으로 전달됩니다.

내용을 검토했다는 확인란을 선택하고 **이 조건으로 실행**을 눌러야 전송됩니다. 내용을 수정하면 확인란이 해제됩니다. **취소**하면 입력한 원래 요청이 남고 AI 실행은 시작되지 않습니다. 요청, 첨부, 모델 또는 실행 경로가 바뀌면 이전 조건으로 전송하지 않습니다.

확정한 조건은 해당 요청과 함께 대화에 기록됩니다. 이미 진행 중인 협업의 답변·발언, AI 확인 질문의 답변, 중지 명령에는 새 작업 양식을 반복해서 표시하지 않습니다. 협업·Owner 직접 지시·계획 실행 경로에서는 실행 작업을 전달하며, 조회 전용 작업은 일반 대화에서 보내야 합니다.

양식은 웹과 데스크톱 입력창에서 지원합니다. 모바일에는 아직 이 양식이 없으며, 기존 모바일 전송과 서버 연결은 유지됩니다. 조건 확인은 작업 내용을 합의하는 기능이며 모든 클라이언트와 외부 도구를 통제하는 보안 경계는 아닙니다.

## Codex 질문 카드

Codex의 일반 질문과 비동기 질문을 카드로 표시합니다. 선택지가 없는 질문에는 직접 답변을 입력할 수 있습니다. 선택지가 미리 선택되어 있어도 답변을 전송하기 전까지 사용자 답변으로 처리하지 않습니다.

Codex가 질문을 남기고 현재 응답을 끝내도 질문 카드는 남습니다. 카드에서 답하면 같은 대화에 답변을 전달하고 이어서 진행합니다. 기존에 선택한 계정·모델·권한·계획 모드를 유지합니다. 협업 단계도 답변을 기다리는 동안 완료로 처리하지 않습니다.

답변 전달 결과가 불명확하면 자동으로 다시 보내지 않습니다. 원래 대화의 진행 상태와 오류를 확인하세요. 제공자가 질문을 닫은 경우와 사용자가 답변한 경우도 구별해 표시합니다.
