# 프로젝트 기억과 AI 입력 설정

프로젝트 제어센터의 **AI 입력 최적화**에서 새 입력에 넣을 기억과 협업 인계를 설정할 수 있습니다. 저장한 설정은 해당 프로젝트의 새 입력에 적용하며, 언제든 끌 수 있습니다. 모델과 추론 수준은 바뀌지 않습니다.

- **작업과 관련된 기억 선택:** 작업·경로와 관련된 자료를 선택합니다. 사용자 필수 지침은 보존하며, 관련 자료가 없으면 기억을 추가하지 않을 수 있습니다. 미리보기에서 선택 이유와 원문을 확인할 수 있습니다.
- **원문을 보존하며 협업 인계 줄이기:** 근거와 미완료 내용을 유지하면서 명시적인 상세 로그나 확인된 중복 인용을 줄입니다. 원문을 확인할 수 없거나 보고서 구성이 불명확하면 전체를 유지합니다.
- **일반 채팅에도 프로젝트 기억 연결:** 직접 보낸 새 메시지에 프로젝트 기억을 연결합니다. 방금 보낸 메시지의 자동 저장 사본은 다시 넣지 않습니다. 기억을 넣지 않던 채팅보다 입력과 토큰 사용량이 늘어날 수 있습니다.
- **프로젝트 문맥 토큰 예산:** 선택한 기억과 외부 자료를 항목 단위로 줄입니다. 현재 작업과 필수 사용자 지침은 원문을 보존하므로 예산을 초과할 수 있으며, 이때 미리보기에 초과량을 표시합니다. 비우고 저장하면 제한을 해제합니다. 저장한 예산은 일반 채팅의 기억 연결과 협업의 프로젝트 문맥 조립에 적용됩니다.

일부 기억만 전달할 때 AI가 필요한 전체 원문을 다시 읽을 수 있는 참조를 제공합니다. 과거 자료를 비교하려면 요청에 과거 비교임을 명시하세요. 문서가 최근에 편집됐다는 이유만으로 기존 근거가 폐기되지는 않습니다.

관련 기억을 선택하는 모드에서는 문맥 안내를 간결하게 구성합니다. 현재 요청·필수 사용자 지침과 선택한 근거 본문, 출처·기록 시각은 유지합니다. 줄어드는 양은 자료 길이에 따라 다르며 모델의 이전 대화와 도구 입력까지 함께 줄어드는 것은 아닙니다.

문맥 미리보기는 현재 작업·필수 지침·선택 기억·외부 자료의 추정 토큰 수를 보여 줍니다. 공통 기준으로 계산하므로 모델별 실제 토큰과 차이가 있습니다. 전체 수에는 구분 문구와 원문 참조가 포함되며, 제공자의 내부 지침·이전 대화·도구·추론과 실제 과금 토큰은 포함되지 않습니다. 프로젝트 문맥 예산은 모델의 전체 컨텍스트 제한이나 비용 상한을 대신하지 않습니다.

협업 인계 축소를 켠 상태에서 산출물이 길면 전체 원문을 보존하고 미리보기와 원문 참조를 전달합니다. 원문 저장에 실패하면 잘린 결과만으로 작업을 완료 처리하지 않습니다.

사용량 화면의 **최근 AI 입력 준비**는 애플리케이션이 구성한 문자 수입니다. 실제 모델 사용 토큰, 캐시 사용량, 완료 비용과는 다릅니다. 제공자 내부 대화와 도구의 입력은 이 문자 수에 포함되지 않을 수 있습니다. 저장이나 미리보기 성공만으로 이미 열린 AI 세션에 기억이 전달됐다고 볼 수 없습니다.

일반 채팅과 오케스트라의 자동 기억 입력은 현재 프로젝트 폴더에 한정됩니다. 다른 프로젝트의 공유 기록과 공용 라이브러리를 자동으로 읽지 않으며, 프로젝트 기억 목록·검색·미리보기도 현재 프로젝트를 기준으로 표시합니다. 공유 원본을 삭제하거나 다른 프로젝트로 옮기지는 않습니다.
