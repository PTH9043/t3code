# 실행 프로필과 완료 후 예약

채팅의 모델 선택 → 협업 설정에서 AI와 모델, 추론 강도, 토론 횟수, 병렬 수, worktree 격리를 선택하세요. 같은 화면의 **재사용 실행 프로필**에서 이름, 공통 지침, 검증 명령을 넣고 **현재 협업 설정으로 저장**하면 다른 기기에서도 선택할 수 있습니다. 프로젝트 운영 화면에서도 저장·적용·삭제할 수 있습니다.

저장한 프로필은 서버가 버전을 부여합니다. **협업 설정에 적용**하면 현재 폴더의 모델과 역할 구성이 바뀝니다. 이후 각 설정을 조정할 수 있고, 다른 폴더의 설정은 바뀌지 않습니다. 공통 지침과 검증 명령은 다음 협업 요청에 포함됩니다. 일반 단일 AI 대화에는 적용되지 않습니다.

프로젝트 운영 → 스케줄러에서 **협업 실행 완료 후**를 선택하고 선행 실행과 후속 명령을 지정하세요. **실행 완료**는 선행 실행이 완료되면 시작합니다. **완료 + 검증 통과 근거**는 완료된 작업 그래프에 통과 판정, 보통 이상 신뢰도, 비어 있지 않은 검증 근거가 저장되어 있어야 시작합니다. 최종 답변의 성공 주장만으로 시작하지 않습니다. 일반 채팅의 응답 완료는 이 예약의 대상이 아닙니다.

선행 실행이 실패하거나 취소되면 후속 예약을 보류하며 이유를 보여 줍니다. 실패 시 취소를 선택하면 예약을 비활성화합니다. 보류된 작업을 다시 진행하려면 새 선행 실행을 선택해 새 예약을 만드세요. 등록된 예약은 중지하거나 삭제할 수 있습니다.

예약은 저장 당시 프로필 버전을 보존합니다. 프로필을 수정하거나 삭제해도 이미 등록한 예약의 모델·지침·병렬 설정이 바뀌지 않습니다. 완료 후 예약은 한 번만 실행하며 서버를 재시작해도 중복 실행하지 않습니다. 다른 프로젝트의 실행을 선행 조건으로 사용할 수 없습니다. AI가 질문이나 승인을 요청하면 기존 답변 흐름을 통해 진행합니다.

모바일의 프로젝트 운영에서도 저장된 프로필로 실행하고, 최근 협업 실행 뒤에 후속 작업을 예약하고, 예약을 삭제할 수 있습니다. 프로필 편집과 시간 기반 예약 등록은 웹·데스크톱에서 지원합니다.

작업 토큰 상세에는 입력 캐시 재사용률과 검증·재시도·형식 복구 단계의 토큰이 표시됩니다. `—`는 해당 수치를 보고받지 못했다는 뜻입니다. 재시도와 검증 항목은 서로 겹칠 수 있으며 총 토큰에 다시 더하지 않습니다. 캐시 항목을 보고하지 않는 제공자가 섞여 있으면 재사용률을 계산하지 않습니다. 잠정·일부 집계 표시와 실제 검증 판정은 별개입니다.

프로젝트 운영의 worktree 현황은 작업, 브랜치, 검증과 최근 실제 활동을 함께 보여 줍니다. Diff 확인 후 기존 소스 제어 흐름에서 변경을 통합하세요. 작업 완료 상태가 병합 완료를 뜻하지는 않습니다.

Telegram 알림·외부 MCP 연결과 자동 앱 배포는 이 기능에 포함되지 않습니다. 외부 계정 연결과 실행 도구 선택은 별도로 설정해야 합니다.
