# AI 사용 도움말

프로그램 왼쪽 상단의 **도움말** 버튼을 누르면 현재 대화를 유지한 채 앱 안에서 HTML 도움말을 읽을 수 있습니다. 사이드바를 접어도 열기/닫기 버튼 옆에 **도움말** 버튼이 표시됩니다. 데스크톱에서는 **도움말 → AI 사용 도움말** 메뉴 또는 **F1**로도 열 수 있습니다.

왼쪽 메뉴 하단의 **AI 사용 도움말**, 설정과 AI 제어센터의 도움말 메뉴에서도 같은 내용을 엽니다. 명령 팔레트에서 `도움말`, `스킬`, `Codex` 또는 `Claude`를 검색해 열 수도 있습니다.

모바일에서는 **설정 → 앱 → AI 사용 도움말**을 선택합니다. 도움말은 앱에 포함되므로 서버 연결이나 인터넷 없이도 본문을 읽을 수 있습니다. 공식 자료 링크를 열려면 인터넷 연결이 필요합니다.

도움말에는 다음 내용이 있습니다.

- 목표·범위·제약·완료 기준을 포함하는 작업 요청 방법과 복사할 예시
- 작성 당시 제공된 스킬의 용도, 호출 예시, 실행 환경 조건
- 내려받아 검토했지만 활성화하지 않은 추가 스킬 후보
- 앱의 파일·터미널·제어센터·검증 증거 기능과 MCP 연결
- 자동 업무 접수함의 양식 만들기·입력·중복 접수 방지와 GitHub 이슈 연결
- AI 호출 전 변화 확인, AI 없이 명령 실행, 실행 프로필·예약 연결
- 산출물 검증과 보류·해제·취소·중단된 작업 재확인·재실행
- Codex·Claude Code의 터미널 명령과 슬래시 명령
- Grok을 통한 X 조사 요청 방법과 문제 해결

검색창에 여러 단어를 입력하면 모든 단어가 포함된 항목을 찾습니다. Ctrl+K는 도움말 검색창으로 이동합니다. 검색 중 Esc를 누르면 검색을 초기화하고, 검색어가 없을 때 Esc를 누르면 도움말을 닫습니다. 닫기 버튼으로도 원래 화면에 돌아갈 수 있습니다.

**복사** 버튼은 요청 예시나 명령을 클립보드로 복사합니다. 명령을 자동으로 실행하지 않습니다. 웹·데스크톱의 **HTML 저장**으로 같은 도움말을 독립된 HTML 파일로 보관할 수 있습니다.

Codex·Claude Code의 슬래시 명령은 해당 CLI의 대화형 터미널용입니다. 앱 채팅에서는 현재 제공자의 `/` 메뉴에 표시되는 기능을 사용하거나 자연어로 요청하세요. 스킬 목록과 명령 지원 여부는 환경·계정·버전에 따라 달라질 수 있으며, 도움말에 확인일과 공식 자료 링크를 표시합니다.

## 자동 업무 안내 찾기

목차의 **자동 업무 · 토큰 절약**을 선택하거나 `자동업무`, `토큰 절약`, `오케스트라`, `재실행`을 검색하세요. 처음 접수하는 순서와 복사할 자료 조사 양식 예시를 제공합니다.

실제 기능은 **프로젝트 운영 → 자동 작업 성과 → 자동 업무 접수함**에서 사용합니다. AI 답변이 끝나도 성공 조건이 없으면 **응답 완료 · 검증 필요**로 남습니다. 서버 중단 뒤 **수행 결과 재확인 필요**가 표시되면 기존 결과부터 확인하고 재실행하세요.

자세한 사용법은 [자동 업무 접수함과 업무 양식](automatic-work-inbox.md)을 참고하세요. 도움말의 업데이트 날짜와 외부 CLI·공식 자료의 확인 날짜는 각각 표시합니다.

## EXAONE 연결

설정에서 제공자 계정 추가를 열고 **EXAONE API 계정 연결**을 선택해 계정 이름과 EXAONE API 키를 저장합니다. 별도 OpenCode 계정에 `k-exaone_v2.5`가 추가되며, 일반 대화와 모니터 비서, 오케스트라에서 선택할 수 있습니다. 기존에 선택한 모델은 바뀌지 않습니다.

OpenCode가 설치되어 있어야 합니다. 키의 유효성과 API 사용 가능 여부는 저장 시 확인하지 않으며, 처음 사용할 때 확인됩니다. 키는 서버의 민감 환경 변수로 관리되지만 로컬 설정 파일은 암호화되지 않습니다.

## Antseed 연결

AI 계정 추가에서 Antseed를 선택한 다음, 키를 발급받은 API 게이트웨이와 실행 환경의
로컬 Antseed 중 사용할 방식을 선택하세요. API 게이트웨이는 주소와 API 키가 필요하고,
로컬 방식은 해당 실행 환경에서 Antseed가 실행 중이어야 합니다. 주소는 `/v1`을 붙이거나
생략해도 됩니다. 연결 확인은 모델 목록을 조회하며 실제 답변 생성까지 확인하지는 않습니다.

## 대화별 비서와 컴퓨터

**설정 → 일반 → 대화 비서**에서 대화를 선택한 뒤 캐릭터와 비서의 이름·역할을 설정할 수 있습니다. 설정은 해당 대화의 다음 요청부터 적용되며, 현재 대화의 사용자 지시가 저장된 역할보다 우선합니다. 모든 대화에 공통으로 적용할 말투와 역할은 **전역 모델 설정**의 **전역 답변 스타일**에서 정합니다. 대화 비서의 역할 적용 범위를 **전역 답변 스타일 사용**으로 두면 그 대화는 전역 답변 스타일만 따릅니다. AI 모델은 대화의 모델 선택 메뉴에서 바꿉니다.

비서 설정에는 별도 비서 서비스 계정이 필요하지 않습니다. 다른 대화에서 이름을 저장한 비서가 있으면 **다른 대화의 비서 설정 가져오기**에서 이름과 역할을 복사해 수정하고 저장할 수 있습니다. 가져오기는 설정의 복사이며 대화 기록이나 작업 공간을 공유하거나 원본에 자동 동기화하지 않습니다. AI 모델은 현재 대화에서 선택한 것을 사용하므로 해당 모델의 기존 이용 조건은 그대로 적용됩니다.

같은 설정에서 **독립 Ubuntu VM** 또는 Docker 컨테이너를 선택할 수 있습니다. VM은 이 PC의 Docker에서 QEMU로 실행하며 CPU 2개, 메모리 4GB, 최대 16GB 디스크를 사용합니다. 첫 기동은 소프트웨어 가상화 때문에 오래 걸릴 수 있습니다. 컨테이너를 선택하면 설치된 Node 포함 Docker 이미지를 지정합니다. 네트워크 차단 또는 연결을 선택하고 생성한 뒤 상태를 확인하세요. 중지와 다시 시작은 내부 파일을 보존하며, **컴퓨터와 내부 파일 삭제**는 해당 파일을 함께 지웁니다. AI 모델은 기존 환경에서 실행되고, 비서 컴퓨터 도구를 요청하면 선택한 VM 또는 컨테이너 안에서 명령을 실행합니다.

입력한 이미지가 설치되지 않았다면 생성 기록을 남기지 않고 오류를 표시합니다. 설치된 다른 이미지를 선택해 다시 시도할 수 있습니다.

생성 중 연결이 끊겼다면 **상태 확인**으로 저장된 소유 표식의 컴퓨터를 다시 찾습니다. `생성 결과 확인 필요`가 남으면 생성 완료 여부가 확정되지 않은 상태이며, 새 컴퓨터를 자동으로 중복 생성하지 않습니다.

이 컴퓨터는 Docker 컨테이너입니다. AI 모델과 일반 호스트 도구 자체가 컨테이너 안에서 실행되는 것은 아니며, 가상머신이나 다른 계정의 앱 연결을 자동으로 제공하지 않습니다. Docker 실행과 선택한 이미지가 필요합니다.

## 모니터 비서의 음성 읽기

모니터 비서에 표시된 마지막 완료 답변은 **마지막 답변 듣기**로 읽을 수 있고, 재생 중에는 **음성 중지**로 멈춥니다. 답변의 언어에 맞는 컴퓨터의 로컬 시스템 음성만 사용하며, 해당 언어의 로컬 음성이 없으면 설치가 필요하다고 표시합니다. 다른 음성 서비스로 자동 전환하지 않습니다. 이 기능은 음성을 입력받거나 음성을 복제하는 기능은 아닙니다.
