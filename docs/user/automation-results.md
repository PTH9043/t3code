# 자동 작업 성과와 검증 자료

프로젝트 제어센터에서 **자동 작업 성과**를 열면 협업·예약 실행과 지속 작업실 작업을 함께 볼 수 있습니다. 모바일에서는 프로젝트 운영 화면에 표시됩니다.

성과판은 최근 작업 50건을 기준으로 완료, 실패, 진행·대기, 명령 검증 통과를 집계합니다. 재시도와 재시도 없이 완료한 작업은 시도 기록이 있는 작업만 집계합니다. 기록되지 않은 값은 0으로 추정하지 않습니다.

**완료**는 작업 응답이 종료됐다는 뜻입니다. **에이전트 통과 보고**는 협업 검증자의 보고이며, **명령 검증 통과**는 해당 후보 커밋의 검증 명령이 모두 종료 코드 0으로 끝나고 시간 초과가 없다는 뜻입니다. 요구사항, 작업실 세대 또는 제어 상태가 바뀐 검증은 갱신이 필요한 상태로 표시합니다. 실행한 검증 명령이 없으면 통과 수에 포함하지 않습니다.

토큰은 해당 작업 ID에 연결된 수집 기록만 표시합니다. 일부 제공자는 사용량의 일부만 보고하므로 수집 범위가 함께 표시됩니다. 수집하지 못한 작업은 전체 합계에 포함하지 않습니다. 지속 작업실의 사용량은 아직 자동 작업과 정확히 연결되지 않아 수집 없음으로 표시됩니다.

작업을 펼치면 시도·재시도, 경과 시간, 작업 대화와 검증 로그를 확인할 수 있습니다. 검증 또는 통합 검증 버튼을 누르면 해당 실행에 저장된 로그가 열립니다. 긴 로그는 앞 64 KiB까지 표시하며, 누락된 로그는 오류로 표시합니다. 검증 자료를 열어도 명령이 다시 실행되지 않습니다.

검증할 때 결과물을 지정하면 해당 검증에서 만든 파일을 별도로 보관합니다. PNG·JPEG·WebP 이미지와 스크린샷, PDF, HTML 보고서, TXT를 지원합니다. 파일당 최대 4 MiB, 한 번에 최대 8개·합계 16 MiB까지 보관하며, 지정한 파일이 없거나 보관할 수 없으면 검증은 실패로 기록됩니다. 이전 검증 기록에 결과물이 없으면 기존 로그를 확인할 수 있습니다.

웹과 데스크톱에서는 이미지·PDF·HTML을 검증 자료 창에서 미리 보고 저장할 수 있습니다. HTML은 읽기 전용으로 표시하며 스크립트와 외부 이미지·글꼴을 제한합니다. 모바일에서는 이미지·HTML을 미리 보고 PDF는 **PDF 열기·공유**로 열 앱을 선택합니다. 보관된 파일이 검증 당시 저장본과 달라지면 표시하지 않고 오류를 알려줍니다.

긴 텍스트는 화면에 앞부분만 미리 표시합니다. 웹·데스크톱의 **파일 저장**, 모바일의 **텍스트 파일 열기·공유**로 불러온 내용을 확인할 수 있습니다. 검증 로그가 64 KiB보다 길면 불러온 앞부분까지 확인할 수 있습니다.

예약 자동화에는 켜짐 여부, 다음 실행 시각과 마지막 오류가 표시됩니다. 성과판은 운영 상태가 갱신될 때 다시 읽으며, 지속 작업실 기록을 즉시 확인하려면 **새로고침**을 누릅니다.
