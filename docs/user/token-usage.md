# 작업 토큰 사용량

대화 입력창의 **작업 토큰 사용량**을 누르면 모델·단계·재시도별 내역을 볼 수 있습니다.
웹과 데스크톱에서는 팝업, 모바일에서는 상세 화면으로 열립니다.
요약은 `12.5만 토큰`처럼 짧게, 상세는 `125,068`처럼 정확한 정수로 표시합니다.

일반 대화의 작업 단위는 한 번의 요청입니다. 협업은 회의·계획·구현·검증·정리를
같은 작업으로 묶습니다. 실패한 시도와 재시도에 사용한 토큰도 합계에 남습니다.
**작업 선택**과 **이전 작업**으로 지난 내역을 조회할 수 있습니다.

이 숫자는 처리한 입력·출력 토큰입니다. 문맥 창 크기, 청구 금액, 구독 잔여량과 다릅니다.
캐시 읽기·쓰기는 입력의 일부이고 추론은 출력의 일부이므로 합계에 다시 더하지 않습니다.
Claude는 하위 에이전트(지휘자 모드의 일꾼 포함)까지 실제로 실행된 모델별로 나눠 보여 줍니다.
Codex의 하위 에이전트는 각자 별도 스레드로 실행되므로, 그 사용량을 하위 에이전트를 만든
요청에 더합니다. 하위 에이전트가 사용량을 한 번도 보고하지 않으면 그만큼은 합계에 없습니다.
다른 제공자의 모델 이름은 실행 요청 당시의 선택값입니다.

## 집계 상태 읽기

| 표시       | 의미                                                                    |
| ---------- | ----------------------------------------------------------------------- |
| 계측 이전  | 계측 도입 전 기록이며 과거 수치를 복원하지 않았습니다                   |
| 미보고 / — | 제공자가 해당 사용량을 보고하지 않았습니다                              |
| 일부       | 보고되지 않은 실행이나 포함 범위가 불확실한 사용량이 있습니다           |
| 잠정 집계  | 실행 중이거나 최종 사용량이 확인되지 않았습니다                         |
| 보고 종료  | 보고가 끝났습니다. 일부 계측이라는 표시가 있다면 누락은 그대로 남습니다 |

Codex와 Claude의 확인된 사용량을 집계합니다. 현재 다른 제공자의 미보고 실행은
부분 집계에 표시합니다. 내장 하위 에이전트의 사용량이 빠지거나 포함 범위가
확인되지 않는 경우에도 전체 사용량이 확정된 것처럼 표시하지 않습니다.
항목별 숫자는 제공자가 보고한 범위의 합이며, **—는 0이 아닙니다**.

대화를 열거나 실행 상태가 바뀔 때, 상세를 열 때 값을 갱신합니다.
다른 대화에서 이어지는 협업이나 진행 중 사용량은 **새로고침**으로 다시 확인할 수 있습니다.
실행 종료와 작업 품질의 검증은 별개입니다.

계측 자체는 모델·추론 설정이나 프롬프트를 변경하지 않습니다.
같은 상세 화면에서 [대화별 인계 문맥 절약](./conversation-handoff.md)을 선택적으로
켤 수 있습니다. 입력 글자 감소량과 실제 토큰 절감률을 구분해 비교하세요.

## 구독 계정 한도

Claude, Codex, Antigravity 구독 계정에서는 5시간 단기 한도와 7일 주간 한도를 계정에서 직접 읽어
**설정 → 제공자**, **AI 제어센터**, 그리고 웹·데스크톱·모바일의 **대화 입력창 사용량 표시**에 함께 보여 줍니다.
Antigravity처럼 모델 계열별 한도가 나뉘는 계정에서는 선택한 모델에 맞는 버킷의 5시간·7일 한도를 입력창에 표시하고, 상세 팝오버와 설정 카드에서 모든 버킷을 함께 보여 줍니다.
웹과 데스크톱 입력창에서는 현재 대화의 컨텍스트 사용률(%)도 링 옆에 항상 표시됩니다.
API 키 방식이나 서드파티 백엔드, 또는 제공자가 한도 정보를 내려 주지 않을 때는
구독 한도 막대 없이 세션 토큰 사용량과 실행 상태만 그대로 보여 줍니다.
