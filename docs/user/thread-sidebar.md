# 프로젝트별 대화 정리

프로젝트는 대화 사이드바의 최상위 항목입니다. 프로젝트를 먼저 선택하면 목록, 검색 결과, 새 대화 만들기 동작이 모두 해당 프로젝트 안에 머무릅니다. T3 Code는 서로 관련 없는 프로젝트의 대화를 하나의 전체 프로젝트 목록으로 합치지 않습니다.

AutoUsage 프로젝트가 있는 환경에서는 사이드바의 **프로젝트별 대화 필터** 목록 맨 위에 **AutoUsage 업그레이드 방**이 표시됩니다. 폴더에 연결할 필요 없이 해당 프로젝트의 일반 대화로 이동합니다. 탭을 닫아도 진행 중인 작업은 계속됩니다.

모든 대화는 만들어질 때 소속 프로젝트를 함께 유지합니다. 딥링크를 열 때도 해당 대화의 프로젝트가 자동으로 선택되므로, 함께 보이는 목록은 항상 열려 있는 작업과 일치합니다.

웹과 데스크톱의 대화 상단에서 캐릭터를 표시하지 않거나 2D·3D 캐릭터를 선택할 수 있습니다. 선택은 대화마다 서버에 저장됩니다. 2D Agustina는 눈을 깜빡이며, 픽셀 및 3D 캐릭터는 작업 상태에 따라 걷기 또는 대기 모습을 표시합니다. 시스템의 동작 줄이기 설정을 켜면 정지된 모습을 표시합니다. 캐릭터 선택은 모델, 실행 권한 또는 대화 내용을 변경하지 않습니다. 모바일 앱의 선택·표시는 아직 지원하지 않습니다.

통합 작업의 **작업자 메시지**를 펼치고 작업자를 선택하면 그 작업자의 대화에 대한 캐릭터도 선택할 수 있습니다. 작업자의 대화가 아직 만들어지지 않은 경우에는 표시되지 않습니다.

컨텍스트 메뉴에서 대화를 고정하면 진행 중인 작업 위쪽의 고정 영역에 남습니다. 고정한 대화는 두 개 이상의 환경에 연결한 경우에도 소속 프로젝트의 목록에 그대로 남습니다.

웹과 데스크톱에서는 고정한 대화를 끌어서 위치를 바꿉니다. 모바일에서는 대화의 메뉴를 열고 **위로 이동** 또는 **아래로 이동**을 선택합니다. 순서는 서버에 저장되며 연결된 다른 기기에도 표시됩니다.

한 환경에서 순서 변경을 사용할 수 없다면 해당 환경에서 실행 중인 T3 Code 서버를 업데이트하세요. 이전 버전 서버도 대화를 고정하고 고정 해제할 수 있지만 동기화된 순서는 이해하지 못하며, 그런 서버의 고정한 대화는 사용자가 정렬한 대화 아래에 기본값인 최신순으로 유지됩니다.

프로젝트를 바꾸거나 대화를 추가·삭제하면 사이드바 목록은 즉시 갱신됩니다. 기본 사이드바와 이전 사이드바 모두 목록 항목이 자동으로 미끄러지는 애니메이션을 사용하지 않습니다.

## 모바일 대기 작업 복구

연결이 끊겨 새 작업의 접수 여부를 확인하지 못하면 모바일은 대기 내용을 보존하고 서버의 기록을 확인합니다. 같은 요청이 이미 접수됐다면 대기 항목을 정리하고, 접수되지 않은 로컬 작업은 원래 선택한 모델과 설정으로 다시 보낼 수 있습니다.

새 작업 트리를 사용하는 경우에는 저장된 준비 단계와 브랜치·경로를 확인해 안전하게 이어갈 수 있는 부분을 복구합니다. 이미 실행한 것으로 기록된 설정 스크립트는 다시 실행하지 않습니다. 작업 트리 생성이나 스크립트 실행 도중 연결이 끊겨 결과가 불확실하면, 중복 실행하지 않고 대기 작업과 기존 상태를 보존하며 확인이 필요하다고 표시합니다. 설정 스크립트의 실행 시작 기록은 성공적인 종료를 뜻하지 않습니다.

# 백그라운드 감시 표시

저장된 대화 상단에서 **감시 꺼짐**을 눌러 그 대화의 감시를 켤 수 있습니다. 기본값은 꺼짐입니다. 감시를 끄면 해당 대화의 감시 중지와 자동 복구 차단을 요청합니다. 진행 중인 일반 답변은 계속됩니다.

감시를 켠 대화에서 AI가 감시를 시작하거나 다음 확인을 예약하면 입력창 위에서 상태를 확인할 수 있습니다. 대화 입력창의 **정지**는 현재 답변을 중지합니다. 개별 감시를 끝내려면 감시 배너의 **중지**를 사용하세요.

서버를 재시작하면 T3는 저장된 기록을 확인하고 감시를 켠 대화에서 복구 가능한 감시만 이어갑니다. 일반 백그라운드 작업의 중단 기록은 감시와 구분됩니다. 중단 알림은 발생 시각부터 기본 30초 동안 표시되고 직접 닫을 수도 있습니다. 설정의 **일반**에서 표시 시간을 바꿀 수 있으며, 알림이 사라져도 작업 기록은 보존됩니다.
