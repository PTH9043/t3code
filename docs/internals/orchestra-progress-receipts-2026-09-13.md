# 오케스트라 이벤트 종료와 진행 표시 보완 — 2026-09-13

## 확인한 문제

- 실행 이벤트 스트림이 종료되거나 결함으로 끝나면 WorkspaceAgentExecutor의 결과 대기가 해제되지 않는 경로를 재현했다. 기존 코드에서는 새 종료·오류 재현 테스트 2개가 각각 60초 제한에 도달했다.
- 제공자 전체 이벤트 구독 또는 Codex 개별 세션의 이벤트 구독이 끝나도 기다리는 실행에 종료 영수증이 없을 수 있었다.
- 작업 목록은 도구 기록을 접힌 상세 영역에만 표시했다. 응답 본문이 그대로인 동안에도 도구가 실행되는지 목록 머리글에서 확인하기 어려웠다.
- 지휘 AI의 질문 때문에 정상적으로 대기하는 실행도 목록 상단에는 '진행 중'으로 표시됐다.

## 수정

- Codex 개별 이벤트 구독이 종료 통지 없이 끝나면 해당 세션의 종료 영수증을 발행한다. 명시적인 범위 취소와 이미 전달한 종료 통지는 중복 처리하지 않는다.
- 제공자 이벤트 구독이 끝나면 그 어댑터가 소유한 미완료 오케스트라 실행에만 종료 영수증을 보낸다. 완료된 실행과 다른 제공자의 실행은 제외한다. 이벤트 연결이 닫힌 어댑터로 새 실행을 시작하면 명시적으로 오류를 반환한다.
- 실행기 자체의 이벤트 구독이 끝나거나 실패해도 대기를 해제하고 기존 중단·복구 절차로 넘긴다. 장시간 무응답을 임의의 시간 제한으로 끊지는 않는다.
- 웹·데스크톱 작업 목록에서 현재 시도의 최근 도구 활동 또는 응답 수신 시각을 표시한다. 접어도 보이며, 이전 시도와 다른 대화의 활동은 섞지 않는다. 시계 타이머나 지속 애니메이션은 추가하지 않았다.
- 지휘 AI의 질문이 남아 있으면 '답변 대기'와 질문 내용을 목록 상단에 표시한다. 질문 답변은 기존 대화 입력창을 사용한다.
