### 긴 산출물과 기억 원문

관련 기억의 일부 청크만 넣는 실행 경로는 선택한 부모 원문을 프로젝트/실행/hash 범위의 파일로 저장하고 읽기/hash 검증 후 참조를 전달한다. 실패하면 전체 원문을 전달한다. 미리보기 조회는 파일을 생성하지 않는다.

협업 축소를 켠 프로젝트에서 긴 발언(20,000자), 의장 정리(지명 공간을 확보한 20,000자), 노드 산출물(100,000자)은 전체 원문 저장을 먼저 완료한 뒤 온전한 문단 미리보기와 파일/hash를 남긴다. 원문 저장 실패를 성공한 잘린 결과로 처리하지 않는다. 미리보기만으로 검증 통과를 판정하지 말고 원문 근거·반대·미완료를 읽도록 안내한다. 기존 terminal 산출물의 160,000자 앞부분 절단을 제거했다. 옵션을 끈 기존 경로의 동작은 유지한다.

약 32,000자 발언/132,000자 산출물의 통합 테스트에서 제한 내 저장, 파일의 전체 본문·끝부분 일치, 의장/검증자 입력의 원문 참조를 확인했다. 이는 scripted seat의 보존·연결 검증이며 긴 자료에 대한 실제 LLM 판정 정확도를 증명하지는 않는다.
