# 세부 기억과 PDF RAG 조사

조사일: 2026-11-06. 다음은 저장소가 설명하는 설계와 T3의 구현을 대조한 기록이다. 외부 코드나 모델 계정 교체 기능을 가져오지 않았다.

- [PyMuPDF RAG 문서, ba7e10069f8ca781246c672ef262506bb2bb54c9](https://github.com/pymupdf/PyMuPDF/blob/ba7e10069f8ca781246c672ef262506bb2bb54c9/docs/rag.rst): PDF 내용을 Markdown·JSON·텍스트로 변환해 검색에 사용할 수 있음을 설명한다. 해당 프로젝트는 AGPL-3.0 또는 별도 상업 라이선스이며 코드를 복사하지 않았다. T3는 기존 PDF.js로 페이지별 텍스트와 선택적 OCR을 이미 제공한다.
- [PDF RAG Pipeline, ba262550b62873f1dd235f489f3931541c246c4b](https://github.com/AnasNexo/pdf-rag-pipeline/blob/ba262550b62873f1dd235f489f3931541c246c4b/README.md): 페이지·청크·출처를 구분하고 검색 결과를 근거와 연결하는 구조를 설명한다. MIT 라이선스. 모델 API 키 순환 부분은 이 사용자의 모델 선택 원칙에 맞지 않아 가져오지 않았다.
- [Microsoft 장기기억 설계, adbefc1874820d3d61a10cbd0776986c33c4205e](https://github.com/microsoft/multi-agent-reference-architecture/blob/adbefc1874820d3d61a10cbd0776986c33c4205e/docs/memory/Long-Term-Memory.md): 사용자가 명시한 기억의 중요도와 필요할 때 검색하는 방식을 설명한다. MIT 라이선스. T3는 이 원칙을 참고해 사용자 결정·조건과 출처가 있는 보고를 선별하되 보고의 미검증 상태와 원본 출처를 유지한다. 선별은 정규식 규칙이며 모델의 의미 이해나 사실 검증이 아니다.

## 측정 범위

기존 지식 검색 평가의 동일 데이터셋·키워드 모드에서 변경 전후 각각 120건 중 96건 통과, 범위 위반 0건, 중앙 추정 입력 261토큰이었다. 이 평가는 지식 검색 경로의 회귀 확인이며 별도 장기기억 선별 전체의 정확도나 실제 모델 답변·요금을 측정하지 않는다. 기존·변경본을 두 차례 교차 실행했으며 각 실행의 중앙값은 약 1.14–1.47ms였다. 이 경로는 별도 장기기억 순위 계산을 직접 측정하지 않으며, 이 정도 실행만으로 성능 향상이나 실제 응답 지연을 단정하지 않는다.

PDF 인쇄용 보기는 구조화된 원본을 변환한 출력이다. 실제 입력 PDF의 OCR 정확도, 이미지 첨부 원본과 스캔 문서의 완전성은 이 변경의 검증 범위가 아니다.
