### 형식 복구

단독 JSON 또는 단독 JSON 코드 블록의 wrapper만 결정적으로 복구한다. 누락된 판정/근거를 자동 생성하지 않는다. parser 거절 시 기존 산출물의 앞부분을 시도 기록에 보존하고 전체 원본의 메시지 ID·길이·SHA-256을 기록한다. 긴 원문은 원래 소유 대화에서 조회하여 hash를 확인한다. 원문 확인에 실패하면 본 작업을 실행하지 않는다.

재시도에는 원 산출물·정확한 오류·필요 형식·사용자 제약만 주고 검색/빌드/수정 재실행 지시를 제거했다. 기존 시도 상한과 완료 노드를 보존하고 형식 복구 비용을 별도 `format-repair` phase에 남긴다. 사용자 좌석 변경은 유지하며 자동 account/model 변경을 피한다. 도구 실패 뒤에도 원본 복구 문맥을 유지한다. 제공자 거부는 자동 반복하지 않는다. native no-tools 정책은 아직 공통 계약으로 지원하지 않으므로 프롬프트만으로 도구 사용을 차단했다고 주장하지 않는다.
