## 동작

- 작업 요청은 지휘 AI의 확인 질문에서 대기한다. 사용자 답변 전에는 토론·작업 그래프·하위 작업 실행으로 진행하지 않는다. 바로 실행(0회 토론)에도 적용한다.
- 답변은 같은 지휘 AI에게 돌아간다. 실행 범위를 확인한 뒤 설정한 토론 또는 계획 단계로 진행한다. 설명 질문이나 “설명만, 작업하지 마”라는 답변에는 답변하고 실행을 종료한다.
- 질문·답변은 기존 대화에 쌓인다. 질문 대기 단계가 저장되므로 복구 시 질문을 건너뛰거나 다시 호출하지 않는다. 기존 중지 경로를 사용한다.
- `askFirst`를 보내지 않거나 끄면 기존 진행 방식을 유지한다.
- 이전 질의응답은 같은 프로젝트·같은 소유 대화의 완료된 실행만 후속 요청에 포함한다. 기존 최근 8개 메시지·12,000자 제한과 프로젝트 RAG 격리를 유지한다.
