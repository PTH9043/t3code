# 오케스트라 대화 맥락·폴더 경계·중지 수정

2026-09-13. 이 문서는 NewAutoUsage 구현과 검증 기록이다. 다른 프로젝트의 대화 원문이나 업무 기억을 공유 RAG로 복사하지 않는다.

## 확인한 결함

- 새 지휘 AI 세션에 실행 요청과 프로젝트 기억만 전달하고, 요청한 대화의 최근 작업 기록은 전달하지 않았다. 짧은 계속 요청에서 과거 기억이 작업 목표로 채택될 수 있었다.
- 자동 입력 구성과 검색이 다른 프로젝트의 environment 범위 기억과 공용 라이브러리를 기본 포함했다. 실제 문제 사례에서 과거 연구 주제가 선택된 것은 확인했지만, 그 자료는 조회 당시 해당 프로젝트 안에 저장돼 있었다. 다른 프로젝트 자료가 그 실행에 실제 주입됐다고 단정할 증거는 없다.
- 취소 처리에서 blocked 노드가 빠졌다. 작업 목록도 실행 전체의 종료 상태를 반영하지 않아 취소 후 대기 항목이 남았다.
- 취소 이벤트는 완료 Deferred를 실패시켰지만, 모델 세션 시작이나 요청 전송이 반환될 때까지 실행이 그 실패를 기다리지 않는 경로가 있었다.

## 변경

- 요청한 대화의 최근 일반 메시지 최대 8개, 약 12,000자를 지휘 AI 입력에 연결한다. 현재 실행이 만든 작업 메시지와 자동 복구 문구는 목표 추론에서 제외한다. 현재 요청과 최근 대화를 목표로 삼고, 기억의 과거 지시는 새 작업 승인으로 해석하지 않도록 명시한다. 대화로 목표를 특정할 수 없으면 확인 질문을 하도록 한다.
- 지휘 AI와 작업 AI는 현재 프로젝트의 관련 기억만 자동 조회한다. 일반 채팅의 자동 기억도 동일한 폴더 경계를 사용한다. 검색·입력 구성에서 공유 기록과 라이브러리는 기본 제외하며, 명시적 API 선택은 유지한다. 원본 기억을 삭제하거나 이동하지 않는다.
- blocked를 포함한 미완료 노드를 취소로 정리하고, 미완료 질문을 닫는다. 작업 목록은 종료된 실행의 오래된 대기/출력 상태도 종료로 해석한다. 중지 중과 중지됨을 구분하고 완료 기록은 보존한다.
- 모델 시작·전송과 취소 신호를 함께 기다려, 시작/전송이 대기 중이어도 취소가 실행을 중단하고 기존 세션 정리 절차로 이어진다.

## 검증

- 관련 10개 테스트 파일, 125개 테스트 통과. 모델 시작·요청 전송을 각각 무기한 대기시킨 회귀 테스트는 Deferred와 실행 종료 결과로 취소·정리·메시지 종료를 확인했다.
- 서버, 웹, 공유 클라이언트 범위 타입 검사 통과. 변경 범위 lint 통과; 기존 reactor의 권고 경고 2개는 남아 있다.
- 실제 취소 기록을 수정된 목록 변환에 입력해 미완료 작업이 모두 취소되고 진행 중인 출력이 0개임을 확인했다.
- 실제 해당 대화의 기존 작업 내용을 사용한 새 입력 구성에서 문제의 과거 연구 기록이 선택되지 않았고, 기본 검색·기억 목록·구성된 입력 모두 다른 프로젝트 출처 0건이었다.
- 기존 dev:desktop 실행 복구 후 웹 5733·백엔드 13773 HTTP 200과 데스크톱 창을 확인했다. 취소한 사용자 실행은 재개하지 않았다.
- 이번 수정에서 새 유료 모델 실행이나 브라우저 클릭 검증은 하지 않았다. 입력 구성·실제 저장 기록 검증과 모델 실행 경계의 결정적 회귀 테스트가 증거 범위다. 이전 모델 실사 성공이 대화 맥락과 취소 경계까지 검증한 것은 아니었다.

## 적용 범위

서버의 기억 경계와 취소 처리는 제공자 및 로컬/원격 접속에 공통이다. 웹과 데스크톱은 같은 작업 목록 표시를 사용한다. 모바일에도 서버가 정리한 새 취소 상태가 전달되지만, 이번 작업에서 모바일 화면은 직접 검증하지 않았다. 기존 종료 실행의 오래된 노드가 남은 원본 데이터는 덮어쓰지 않았다.
