# Claude·Codex 캐시 적용 기록

분리된 개발본 `D:/__NewAutoUsage-auto-20261015`에서 구현했다. 운영 데이터는 `E:/NewAutoUsage`를 유지한다. 이 기록은 설계 문서의 첫 적용 범위와 실제 검증 범위를 구분한다.

## 적용 기능

- 프로젝트 필수 지침과 공통 문맥의 순서를 안정화하고 현재 작업을 뒤에 배치한다. 필수 지침의 내용 변경은 즉시 반영한다.
- Claude의 메인/내부 하위 요청에 각각 `inherit`, `5m`, `1h`를 선택한다. 기존 설정은 inherit이며 새 SDK query에만 적용한다.
- 오케스트라의 바로 다음 재시도는 같은 실행·노드, 계정, 모델·옵션, cwd, 권한이고 이전 세션이 종료된 경우에만 저장한 native cursor를 이어간다. 실행 키는 매 시도 새로 만들어 늦은 이벤트가 새 시도에 섞이지 않게 한다.
- 종료 직전 최신 cursor를 저장한다. Codex native resume fallback은 식별하고 대화 인계를 준비한다.
- Codex의 선택형 캐시 쓰기, Claude의 5분/1시간 쓰기 내역을 보존한다. 세부 항목을 총량에 다시 더하지 않는다.
- Codex 재개 시 첫 누계가 이전 잔액일 수 있어 별도 counter epoch와 확인된 기준값을 사용한다. 기준값이 부족한 구간을 새 소비량으로 추정하지 않는다.
- Claude가 `subtype: success`, `is_error: true`로 보내는 크레딧 부족 응답은 실패로 표시한다. 미보고 사용량을 0으로 만들지 않는다.
- 동일 프로젝트의 문서 추출에 내용·파서·OCR·MIME·확장자·새로고침 세대 기반 SQLite 캐시를 적용한다. 매번 실제 바이트와 결과 해시/형식을 검증하고 동시 요청은 합친다. 실패·부분 추출·취소는 완료 캐시로 저장하지 않는다.
- 문서 캐시는 최대 7일, 128개, 총 32MB, 한 결과 1MB다. 오류 시 원본으로 처리하며 기존 증거 파일을 보존한다. 설정에서 재사용을 끄거나 새로고침할 수 있다.
- 웹·데스크톱 설정과 공통 도움말을 갱신했다. 사용량 세부 표시는 웹·모바일 공통 상태 모델을 사용한다. 서버 정책은 로컬·원격 클라이언트에 동일하게 적용된다. 새 Claude 정책 편집은 웹·데스크톱에서 제공한다.

## 적용 범위의 경계

현재 결과 캐시의 호출자는 문서 추출이다. 일반 웹 검색·GitHub 최신 상태·코드 실행·AI 답변 전체를 캐시된 완료로 대체하지 않는다. 기존 자동 접수함의 변화 사전 확인, 중복 이벤트 방지, 의존 노드 결과 전달은 그대로 사용한다. 일반 조사 AI 호출을 역할 간 자동 합치거나, 임의 도구 실행을 캐시하는 기능까지 완료했다고 주장하지 않는다.

고정 문맥 배치와 native 재개는 캐시 가능성을 높이는 동작이며, 서비스 캐시 적중 보장은 아니다. 원래 입력 토큰 수, 캐시 처리 비용, 구독 한도 사용량은 서로 다른 지표다. 사전 예열용 AI 호출은 추가하지 않았다.

## 검증

- 변경 관련 19개 파일, 353개 테스트 통과. 문서 해시 변경·범위 격리·만료·중복 요청·취소·손상 결과·용량 상한, 세션 재개 조건, 누계 중복, fallback 인계, 설정과 도움말을 포함한다.
- 서버·웹·contracts·client-runtime·shared 타입 검사 통과.
- 모바일 타입 오류 69개는 운영 원본과 동일하며 새 오류 0개. 변경 파일 lint의 기존 진단 11개도 운영 원본과 동일하며 새 진단 0개다. 이 검사를 전체 통과로 표기하지 않는다.
- 웹, 서버 번들과 데스크톱 빌드 성공. 후보 서버 HTTP와 인증된 WebSocket 설정 저장/조회 성공. 문서 캐시 테이블을 포함한 후보 SQLite `quick_check` 통과.
- Codex 실호출은 기존 선택과 같은 `gpt-6-astra`, reasoning `max`, service tier `priority`로 새 대화·후속 턴·종료 후 재개를 확인했다. 세 응답 모두 기준 정답을 반환했고 도구 사용은 없었다. 마지막 확인의 입력은 30,446 → 60,961 → 91,530, 캐시 읽기는 0 → 30,208 → 60,544로 누적 보고되었다. 이는 기능 확인이며 변경 전 대비 절감률이나 통계적 성과 실험이 아니다.
- Claude `claude-fable-5` 실호출은 native CLI가 사용 크레딧 소진을 보고했다. 정상 캐시 읽기·쓰기 효과는 미검증이며, 오류를 정확히 전파하는 동작은 실호출로 확인했다. TTL 설정 전달과 사용량 정규화는 SDK 집중 테스트로 검증했다.
- 사용자 화면을 전면에 띄우거나 조작하지 않았다. 이번 검증은 자동 테스트·HTTP·WebSocket·프로세스·로그에 근거하며 새 화면의 시각적 검증 완료를 주장하지 않는다.

최종 교체·재시작·데이터 보존 증거는 운영 작업 디렉터리 `.t3/cache-upgrade-20261015/`의 완료 영수증에 별도로 기록한다. 소스와 빌드 롤백은 가능하며, 새 실행 뒤 데이터베이스를 과거 스냅샷으로 덮어쓰지 않는다.
